# 路线图

## M0：起步纵向切片（已完成）

完成安装可构建的 Tauri/React/Rust 工程、SQLite 增量索引、私有缩略图、基础亮度/饱和度/主色、可取消扫描、图库恢复、基础排序、语义接口和自动化测试。不输出真实语义标签。

## M1：安全整理闭环（下一里程碑）

- 完整连续影调/色彩特征与阈值标签。
- 组合筛选、多级稳定排序、虚拟化网格和原图预览。
- 目录层级与命名模板解析、即时 dry-run、Windows 路径校验和冲突策略。
- 只复制执行、预写日志、磁盘/权限检查、崩溃恢复和哈希保护的撤销。
- 完善相机/镜头/曝光元数据；评估是否随包分发 ExifTool。

## M2：可选语义分析

- 建立许可明确的小型评测集和候选模型矩阵。
- 基准轻量固定分类器、轻量图文模型及条件检测组合。
- 选择并集成合规 ONNX 模型、自动 provider 探测、批处理、暂停/恢复和版本失效。
- 只有经过校准/评估后才设置默认阈值，UI 始终称“相似度”或“置信分数”。

## M3：发布加固

- 大图库性能、内存和数据库恢复压力测试。
- 安装/升级/卸载、杀软误报和多 Windows 版本矩阵。
- 正式代码签名、SBOM、第三方与模型许可证归档。
- 可选的应用内模型下载器；不阻塞离线基础功能。

## 明确不在近期路线图

人脸身份识别、云同步、账号、远程后端、移动端、视频、专业 RAW 显影、从头训练/微调大模型、大模型描述、永久删除、默认移动、原地批量重命名、订阅和付费在线功能。任何加入都需新的产品决策和安全评审。
