# 产品需求

## 产品目标

PhotoOrganizer 为 Windows 用户提供无需云服务的本地图片索引、虚拟分类和安全整理工作流。普通浏览和分析永远不改变原目录；所有物理文件操作必须先生成可审查计划，默认复制，禁止静默覆盖。

## 角色与核心流程

单机用户安装并启动应用，选择一个根目录。应用立即递归扫描并逐步显示缩略图，先完成元数据和传统图像分析，再由独立后台任务补充可选语义标签。用户可筛选、分组、稳定排序，并在后续里程碑预览目标目录/名称后复制文件和撤销生成的副本。

## 起步纵向切片（本次）

### 必须具备

1. 首次启动空状态与系统文件夹选择器。
2. 递归发现 `.jpg`、`.jpeg`、`.png`、`.webp`，扩展名不区分大小写。
3. SQLite 初始化、迁移、图库恢复、路径唯一约束和增量更新。
4. 单文件失败不终止扫描；进度包含发现、处理、成功、失败、跳过和缺失数量。
5. 支持取消；扫描在后台运行并用事件增量通知 UI。
6. 应用私有缩略图缓存、缓存命中与源修改后的失效。
7. 宽高、方向、拍摄时间（可读取时）、修改时间和文件大小。
8. 平均亮度、平均饱和度、基础主色及合法数值范围。
9. 图片网格、加载/错误状态、详情面板和文件名/时间/亮度/饱和度排序。
10. 随包 TinyCLIP INT8 在 CPU 上进行真实本地多标签分类；分类器、执行后端、模型元数据、任务状态和基准 CLI 可替换，无模型时明确 unavailable。
11. 无扫描或分析路径会写入、移动、重命名或删除源图片。

### 可接受限制

- 当前网格面向起步规模，超大图库的真正窗口化虚拟滚动在下一里程碑完成。
- 起步版本只读取常见 EXIF；相机/镜头/完整曝光字段在后续完善。
- 第一版语义质量使用固定 prompt 与阈值，尚未在授权真实摄影评测集上完成逐类 precision/recall 校准。
- 文件整理执行尚未开放，但表结构和服务边界保留。

## 完整 MVP 能力

### 元数据与分析

保存可索引的连续值，而不仅是离散标签：亮度均值/中位数/分位数、暗部/高光比例、对比度、动态范围近似、饱和度统计、主色列表、色相分布、中性色比例、冷暖评分、色彩丰富度和近黑白概率。透明像素、边框、方向、小图和损坏文件必须有确定行为。

### 语义层

多标签结果包含标签、相似度、模型/分析版本、时间、人工修改和排除标志。目标类别包括人物、风景、山水、森林、花卉、日落、夜景、建筑、室内、街道、车辆、产品、静物、食品、动物、截图、文档、海报、抽象与未知。相似度不得表述为校准概率。

### 浏览

支持组合筛选与多级稳定排序。界面明确区分原始目录、虚拟分类和目标整理目录。

### 规划和文件安全

提供可组合目录层级、命名变量、缺失回退、Windows 非法字符/保留名/路径长度检查、冲突检测、序号和短哈希。执行前完整 dry-run；MVP 只复制到新目录、不覆盖；操作先记日志，可取消和恢复；撤销只删除由应用生成且哈希未变化的副本。

## 非功能要求

- 离线优先，无账号、远程后端、API Key 或数据库地址配置。
- 基础功能 CPU 可用；可选语义推理自动选择可验证硬件后端并回退 CPU。
- 扫描和语义任务可增量、可取消；语义任务支持暂停、恢复和重启续作。
- Unicode 路径是一级用例。
- 安装包自包含运行组件；正式发布需代码签名与第三方许可审计。

## 明确排除

人脸身份识别、云同步、账号、移动端、视频、专业 RAW 显影、模型训练、大模型描述、永久删除、默认移动、原地批量重命名、付费在线功能、正式签名和完整自动更新不在本次范围。
