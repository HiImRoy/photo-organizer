# ADR-0003：模型分发

- 状态：已接受
- 日期：2026-08-06

## 决策

起步版本不分发语义模型。候选权重只有在模型卡、权重许可证、训练数据限制、商业/再分发条款、导出格式和目标类别基准全部审核后，才能进入发布清单。

体积适中的合规模型优先随安装包分发并附 SHA-256/版本元数据。只有包体明显不可接受时才采用应用内下载；下载器必须提供进度、暂停、重试、完整性校验和原子安装，失败时基础功能继续可用。用户不会手动选择模型目录或配置环境变量。

## 结果

- 当前 UI 和 API 明示“可选模型未安装”。
- 仓库许可证不能替代模型权重许可证。
- 模型更新与应用数据库中的 `model_name`、`model_version`、`analysis_version` 绑定；版本变化只标记旧结果失效，不伪装为新结果。
