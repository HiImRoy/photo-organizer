# ADR-0015：统一筛选、预览与安全原文件复制

- 状态：Accepted（2026-10-19）；主要实现已集成，最终验证与桌面验收未完成
- 日期：2026-10-20（设计接受于 2026-10-19）
- 主方案：[0083 核心 MVP 方案](../plans/0083-core-mvp-filter-preview-folder-export.md)
- 技术合同：[核心 MVP 技术附录](../plans/0083-core-mvp-technical-appendix.md)
- 相关决策：[ADR-0014：Windows 导出回滚绑定文件句柄](0014-handle-bound-windows-export-rollback.md)

## 背景

提交本 ADR 时，应用已有组合筛选、网格和多种预览、编辑副本以及 Organization 试排；分组统计依赖已加载照片，部分预览错误会影响整组状态，试排清单也不足以恢复为完整执行计划，原文件 Safe Copy 尚未实现。2026-10-20 的实现进度和未完成验收见下文及 0083 主方案。

本 ADR 只确定核心 MVP 的设计边界与取舍。完整字段、状态、目录检查、故障处理和测试合同见技术附录。

## 决定

1. **沿用现有架构。** 保留本地桌面端、现有前后端和 SQLite，不引入服务或生产依赖。

2. **统一筛选和批量范围。** 用户可针对全部匹配结果或明确选中的照片操作。总数、分组与分页由同一查询条件计算，不能以界面当前已加载照片代替全量结果。

3. **先预览并保存完整计划。** 计划记录来源范围、组织方式、目标位置、冲突和逐项结果。旧格式计划只允许查看，须重新生成后才可执行。

4. **按原字节复制并共用安全文件操作层。** 来源只读，不转码、不覆盖。复制、验证、操作记录和受限撤销沿用 ADR-0014 的文件句柄安全边界。

5. **Safe Copy 使用最小数据库恢复门槛。** 以一致的 SQLite 快照、校验、恢复演练和迁移前备份替代完整 N3 产品作为本轮实现前置。完整用户备份/恢复界面与跨设备迁移仍后置，风险必须持续披露。

## 方案取舍

| 选择                   | 收益                                       | 代价或限制                              |
| ---------------------- | ------------------------------------------ | --------------------------------------- |
| 在数据库中解析完整结果 | 不受滚动位置和已加载页面影响，统计可复核。 | 需要保存可恢复的逐项计划。              |
| 复制原文件内容         | 来源保持只读，文件字节不经图像重编码。     | 文件系统时间等属性不承诺复制。          |
| 共用安全文件操作层     | 写入、验证、记录和撤销使用同一保护边界。   | 新任务须接入 ADR-0014 的句柄约束。      |
| 先做最小恢复检查       | 在复制前证明数据库快照可读且可恢复。       | 不提供设备或磁盘损坏后的完整自助恢复。  |
| 保持完整 N3 产品先完成 | 保留完整用户恢复路径。                     | Safe Copy 将继续等待更大的产品工作。    |
| 直接复制活动数据库     | 实现看似简单。                             | 可能遗漏 WAL 中已提交的数据，因此禁止。 |

## 路线图门禁与历史

旧 roadmap 的“完成完整 N3 前不开放 Organization Safe Copy”历史门禁，已由本 ADR 接受后的范围调整替代：Safe Copy 只需先通过技术附录定义的最小数据库恢复门槛。门槛实现已接入并用于隔离 scan→plan→copy 流程；最终后端检查仍在进行，桌面验收尚未完成，因此不把 Recovery Gate 或整个功能标为已验收。这不代表 N3 已整体完成；完整用户备份/恢复功能仍需另行跟踪。

本 ADR 将本任务生成副本的有限撤销纳入当前 MVP，以满足既有 MVP 范围；这不是任意删除能力。旧 Checkpoint 与路线图历史保持原样。

## 安全边界与影响

- 只写入新建目标文件夹；不得覆盖现有文件。
- 目标必须与所有照片来源及应用数据目录分离；无法证明安全时拒绝执行。
- 取消或崩溃时保留已完成项。句柄丢失后的不完整文件隔离核对，不自动删除或重放。
- 撤销仅处理本任务创建、身份和内容仍匹配的副本；原图和目录保留。
- 该设计遵守 ADR-0014 的 Windows 文件系统边界，不保证抵御任意恶意祖先目录重挂载。
- 原图只读；导入、分析和模型处理仍须遵守应用缩略图边界。
- Places365 分类资源哈希差异已在本轮按上游固定版本与仓库规范 LF 字节诊断并更新资源校验合同；本次全量资源检查通过，但本 ADR 不把它视为功能验收或 CI 发布通过。证据见[本机接收记录](../handoff/2026-10-19.md)。
