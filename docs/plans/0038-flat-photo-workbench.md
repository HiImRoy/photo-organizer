# 0038 Flat Photo Workbench UI 重构

## 目标

将 PhotoOrganizer 的前端从“新拟物卡片工作台”重构为面向个人摄影师的扁平化桌面工作台（Flat Photo Workbench）。视觉应体现图库、暗房、胶片带和检查器的工作语境，避免通用 SaaS、AI 生成式卡片和装饰性控件。

## 约束与假设

- 保留 Tauri 2 + React/TypeScript + Rust 的现有架构；Tauri WebView 是桌面应用的 UI 载体，不迁移到 WinUI/WPF。
- 不修改扫描、缩略图、分析、模型、SQLite 和安全导出链路。
- 继续遵守缩略图专用规则：页面重构不能把原图路径传给导入、分析或模型流程。
- 现有 `App.tsx` 和 CSS 作为行为基线；先整理前端壳层边界，再逐步拆分，不做一次性大规模业务迁移。
- 视觉重构必须同时支持深色和浅色主题，布局和交互不能因主题切换而分叉。

## 设计结论

### 视觉命题

“摄影师的本地暗房目录”：图片是主内容，工具栏是操作台，左侧是胶片/图库目录，右侧是检查器。结构用分栏、分割线、缩进和文字层级表达，不使用大量浮起卡片表达层级。

### 视觉 token

- 工作区容器使用 `12–14px` 圆角，图片卡片使用 `10–12px`，控件使用 `7–9px`；不使用 999px 胶囊式主操作。
- 移除新拟物高光、渐变背景和大面积发光；保留极弱的普通阴影表达容器悬浮，弹出层使用更深但克制的阴影。
- 深色：画布 `#191919`、侧栏 `#202020`、面板 `#242424`、悬停 `#2b2b2b`、选中 `#333333`。
- 浅色：画布 `#f7f7f5`、侧栏 `#f0f1f1`、面板 `#ffffff`、悬停 `#e8e9e8`、选中 `#dde3e5`。
- 强调色使用低饱和灰蓝，只承担当前项、焦点和主要操作语义；星级、色标和错误保留语义色。
- 字体采用系统 UI 字体，正文 12–14px，辅助信息 10–12px，数字使用等宽数字特征。

### 页面骨架

```text
顶部工具栏：当前图库 / 搜索 / 筛选 / 排序 / 导入 / 分析
左侧导航：图库、筛选
中央工作区：结果上下文 / 网格或单图预览 / 胶片带
右侧检查器：导航图 / 文件与 EXIF / 直方图 / 分类与分析
底部状态：任务进度、选择数量、当前视图提示
```

## 实施顺序

1. 建立最终 token 和扁平化 shell 样式，确保既有行为不变。
2. 将顶部批量操作和工作区上下文改成明确的桌面工具栏层级。
3. 逐步把 `App.tsx` 中的 shell、工具栏和状态栏拆成独立组件；业务回调先保持原有签名。
4. 将设置、快捷键和面板布局纳入统一的应用设置边界，不在组件内散落保存。
5. 使用视觉夹具验证 `library`、`scanning`、`error` 和浅色主题，之后再处理整理/审阅工作区。

## 验收标准

- 主面板、侧栏和信息栏不再出现大圆角卡片或新拟物内外阴影。
- 视觉层级仍能通过分栏、分割线、背景差和选中状态清楚辨认。
- 1440×900、1366×768、960×720 不出现横向溢出；左右面板仍可调整宽度。
- 网格、单图预览、胶片带、筛选、批量操作、导入和分析入口行为不回归。
- `npm run typecheck`、`npm run lint`、`npm run test`、`npm run build` 通过。
- 以 Tauri 入口启动时窗口和 IPC 行为保持不变；不以浏览器预览替代桌面验收。

## 本轮界面审查修正（2026-08-17）

- 左侧图库区域与筛选区域按可拖动分隔线分配高度并分别滚动；图库区域不再保留旧的 viewport 高度上限。来源（收藏/虚拟集合）位于筛选栏底部，不作为第三个侧栏模块。
- 顶部工具栏拆成“浏览控制”和“图库操作”两组；查找与审阅、整理预览收进“更多”菜单，导入、分析和主题切换保留为直接操作。
- 图片卡片的评分/色标控件改为卡片内部的交互浮层。未设置人工标记时不占布局高度，不再生成空的深色底栏；已有标记或悬停时仍可直接编辑。
- 日期筛选改为左栏内的两行布局，禁止原生日期输入把侧栏撑出横向滚动条。
- 右侧信息栏收敛为单层检查器轮廓，内部 `right-panel-card` 不再重复绘制圆角、边框和背景卡片。
- 筛选项改为等宽两列导航单元，计数固定右对齐；影调和饱和度保留三列紧凑选择，选中态使用单条灰蓝强调线。
- 浅色主题直方图改用对比度安全的中性底、网格和通道描边，保证 `A/L/R/G/B` 的默认/切换状态都能辨认。
- 清理侧栏、筛选弹层、欢迎页和审阅工作区的重复副标题/解释；可见标题统一为“筛选”，只保留当前范围、错误、进度和原图只读等有操作价值的状态信息。
- 整理预览中的英文眉题和重复的 SQLite/dry-run 说明改为中文或移除，安全边界集中在顶部只读提示中。
- 恢复图片卡片的人工标记交互：未悬停时仅显示 `3⭐` 等结果摘要和色标背景，悬停/键盘聚焦时显示编辑框；未选星级使用描边、已选星级连续填充。
- 颜色环、匹配严格程度、亮度范围和饱和度范围位于左侧筛选栏顶部；顶部“筛选”弹层只保留当前条件，侧栏模块内部不再套嵌相同圆角容器。
- 新增设置对话层与本地持久化配置：快捷键可编辑，导入 worker 数（1–2）和分析批大小（1–8，默认 4）会传入下一次对应任务；当前分析任务仍限制为单 worker。
- 已使用前端夹具检查过深色、浅色主题及“更多”菜单；本轮新增的筛选弹层、设置弹层和可配置任务参数已通过自动化测试与构建验证，尚未用真人图库做桌面窗口视觉验收。
