# 0056 多图网格自适应预览清晰度

状态：已实现。

## 问题

`grid-640-v1` 足以支持 8～12 张/行的密集网格和全部分析流程，但在 2～6 张/行时会被放大，尤其在高 DPI 屏幕上明显发糊。网格不能因此一次性装载大量大图，也不能把原图路径交给前端或分析链路。

## 决策

| 每行数量 | 显示资源                   |
| -------- | -------------------------- |
| 2        | `screen` 1280×960 有界预览 |
| 4        | `screen` 960×720 有界预览  |
| 6        | `screen` 768×576 有界预览  |
| 8～12    | 现有 `grid-640-v1` 缩略图  |

高清档位是应用私有 screen preview，不是 original。它通过已有有界解码器生成并缓存，不参与导入、特征分析或模型推理。

## 性能边界

- 640px 缩略图先显示，高清资源完成后原位替换，保持渐进清晰。
- 只有中央网格视口附近的卡片请求高清资源；普通缩略图仍使用原有 720px 预取窗口。
- 高清请求使用独立队列，最多并发 2 个，不阻塞普通缩略图队列。
- 前端只缓存最近 48 个高清 data URL；离开高清可见范围后回退到普通缩略图。
- 8 张及以上每行不创建新的 screen preview。

## 验收

- 2、4、6 张/行分别请求固定的 1280、960、768 档位。
- 8、10、12 张/行只请求 `grid-640-v1`。
- 高清生成失败时卡片继续显示普通缩略图。
- 测试覆盖档位映射和最多 2 个高清并发请求。
