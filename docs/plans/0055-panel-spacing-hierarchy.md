# 0055 工作区板块间距层级

## 目标

让圆角工作区板块与相邻边缘保持稳定、可感知但不松散的间距，同时保留左侧“图库”和“筛选”作为一组紧凑的导航模块。

## 现状问题

- 工作区外层最终样式使用 4px 内边距和 2px 列间距，顶栏、左侧栏、中间画布和右侧检查器容易贴在一起。
- 中央扫描任务、图库工作区和整理/审阅工作区各自使用不同的 margin，板块之间的节奏不一致。
- 左侧图库与筛选之间的 10px 高度拖拽区是有意义的交互分隔，不应被通用板块间距覆盖。

## 决策

- 新增 `--workspace-panel-gap`，桌面宽度下使用 8px，窄窗口通过 `clamp()` 收窄到 6px。
- 工作区外层内边距和列间距统一使用该 token；顶部和左右边缘因此都有明确留白。
- 中央列使用同一 token 作为内边距和子板块之间的 gap，扫描任务、图库、整理/审阅区域不再各自计算 margin。
- 左侧导航栏仍保持透明结构容器；图库/筛选模块之间的 10px 高度拖拽区保持不变。
- 不修改图片卡片间距、侧栏筛选内部行距、缩放逻辑或数据行为。

## 验收

- 深色和白天主题下，中央图库、右侧信息和任务/审阅板块与相邻边缘均有统一间距。
- 左侧图库与筛选仍可拖动分隔线，默认比例和独立滚动不变。
- 960×720 及以上窗口不出现横向溢出；窄窗口间距收窄但不消失。
- 前端格式、lint、类型检查和测试通过。
