# 0052 搜索结果与原图库交互统一

## 背景

AI 搜索结果当前只支持聚焦图片，不能像主图库一样进行批量勾选、星级和色标标记；双击结果也不会回到原图库，导致搜索结果与主浏览流程割裂。

## 方案

- 搜索结果卡片复用主图库的三类状态：当前图片描边、独立的圆形批量选择按钮，以及悬停/键盘焦点时出现的星级和色标编辑层。
- 星级和色标更新继续走主界面的现有 API 与批量选择逻辑；搜索结果只做局部乐观更新，不创建第二套持久化状态。
- 搜索结果单击只改变当前图片；单独点击圆形选择按钮才改变批量选择集合，并保留 Ctrl/Shift 修饰键语义。
- 搜索结果双击关闭搜索浮层、回到图库网格、将结果设为当前图片，并按当前图库加载范围滚动到对应卡片；当前查询未包含该图片时，使用详情数据补入可见结果作为安全回退。
- 结果缩略图仍通过既有缩略图 IPC 加载，不引入原图解码。

## 验收

- 搜索结果中可以直接使用圆形选择按钮、星级和色标；单击缩略图不会误勾选。
- 已选择图片后在搜索结果里标记星级/色标，主图库和搜索结果状态保持一致。
- 双击搜索结果返回主图库，当前图片描边出现在对应卡片上，批量选择状态不被意外改变。
- 结果卡片在深色/浅色主题和窄宽度下保持统一圆角控件、可见键盘焦点和缩略图加载路径。
- 通过格式、类型检查、lint、前端测试和构建。
