# Plan 0010：修复单张预览工作区高度

## 问题

未打开“批量修正”栏时，应用仍按“顶部栏 + 批量修正栏 + 工作区”三行布局计算。工作区被放在第二行，第三行保持为空白，导致单张预览、导航图和胶片条被压缩到窗口顶部。

## 修复范围

- 仅在批量修正栏实际显示时保留三行布局。
- 批量修正栏关闭时，让工作区跨满顶部栏以下的剩余高度。
- 不改动原图加载、缩放、拖动、选择或胶片条交互。
- 图库区域不再使用包住整棵树的外层大卡片；导入入口固定在“图库”标题栏右侧。

## 验收

- 单张预览应从内容工具栏延伸到窗口底部。
- 导航图、预览图和胶片条应处于同一个完整高度的预览工作区内。
- 打开批量修正栏时仍保留独立的批量编辑行。
- 前端测试、类型检查、Lint 和构建通过。
