# Plan 0009：单图选择与可调三栏工作区

## 目标

让单图预览保持 Lightroom 式工作流：当前图片在放大预览中仍然可以加入/移出选择集合；左侧把图库管理与分类筛选分成两个清晰区域；左右信息面板通过拖拽分隔条调整宽度。

## 实施范围

1. 在单图预览画布中增加当前图片选择按钮，并沿用现有 `selectedAssetIds`、Shift/Ctrl 选择和批量操作数据流。
2. 为胶片栏保留当前图片导航，同时用选择状态边框区分已选图片。
3. 将左侧 Sidebar 分为“图库”和“分类与筛选”两个独立的垂直区域；图库树和筛选内容各自滚动，不改变 Library 数据模型。
4. 在左右面板与中央画布之间增加可访问的垂直拖拽分隔条；设置最小/最大宽度，面板始终显示，不再增加折叠按钮。
5. 使用 CSS 变量承载面板宽度，保持现有石墨灰主题、按钮状态和响应式最小宽度。
6. 增加单图选择、面板宽度和 Sidebar 分区的前端回归测试，并更新功能/界面文档。

## 非目标

- 不改变单图预览的原图读取、缩放、拖动画布和 Navigator 逻辑；
- 不改变 Library、Asset 或 FilterState 数据模型；
- 不增加磁盘文件操作、源文件修改或新的远程依赖。

## 验收标准

- 单图预览中点击“选择/取消选择”可更新顶部选择数量，并可继续执行分析、人工标记和拖动到图库；
- 胶片栏能区分当前图片和已选图片；
- 左侧“图库”与“分类与筛选”视觉分隔，分类区域不会被图库树无限推到屏幕外；
- 拖动左/右分隔条只改变对应面板宽度，不移动图片或修改源文件；
- 面板宽度有安全上下限，键盘方向键仍可用；
- `npm run typecheck`、`npm run lint`、`npm test -- --run`、`npm run build` 通过。
