# 0039 浏览工具栏与可选分组

## 目标

减少中央图片区域顶部的常驻占用，将结果摘要、分组和分析状态收敛为一条轻量工具栏；把原先写死的“按拍摄题材分组”改为可选择的浏览分组。

## 决策

- 分组属于前端浏览状态，不属于 `AssetFilter` 或 SQLite 查询条件；切换分组不重新扫描、不重新分析，也不改变筛选结果。
- 默认值为“不分组”；可按拍摄题材、主体标签、影调、饱和度级别、主色和评分分组。
- 分析状态筛选仍然保留，但只在存在待分析图片或已选择状态筛选时以内联控件显示，不再独占一整行。
- 多值主体/主色使用稳定的第一个有效值作为展示分组，避免同一图片在多个分组重复出现。

## 验收

- 顶部只有一条结果工具栏，不再显示常驻的独立分析横条。
- 分组下拉框可切换上述维度，选择“不分组”恢复普通网格。
- 当前筛选、选择、排序和分析状态筛选行为保持不变。
- 前端格式、lint、类型、测试和构建通过。
