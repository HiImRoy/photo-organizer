# Plan 0008：人工星级与色标

## 目标

修正资产卡片选择控件的定位和侧栏主色色块的窄栏布局，并为图片增加 Lightroom 风格的本地人工标记：

- 星级：0–5 星；
- 色标：红、黄、绿、蓝、紫；
- 标记保存在 PhotoOrganizer 的 SQLite 元数据中，不写回原图；
- 卡片使用色标边框和轻微单元背景色表达人工色标，星级同时提供可见星标；
- 支持按星级和色标筛选；星级筛选一次只选择一个明确的星级阈值，并匹配该星级及以上，不允许出现多个互相重叠的星级筛选状态。

## 实施范围

1. 修复 `.asset-check` / `.asset-mark-toggle` 的绝对定位，保证选择钩锚定在卡片左上角。
2. 让主色筛选在窄侧栏中自动换行，避免固定列数和最小宽度造成溢出。
3. 增加 `rating` 和 `color_label` 数据字段、迁移、索引、查询筛选和 IPC 更新命令。
4. 在卡片和详情面板提供无需手动输入的星级、色标选择控件，并支持选中多张图片后批量应用。
5. 提供 Lightroom 风格的 `0–5` 星级、`[` / `]` 调整星级、`6–9` 色标快捷键；再次按当前已设置的同一色标快捷键清除该色标。
6. 增加人工标记筛选，并保持自动“主色”和人工“色标”语义独立。
7. 补充前端、数据库和视觉夹具测试，更新用户可见功能文档。

## 非目标

- 不修改图片文件、EXIF 或 XMP；
- 不把人工色标当作自动主色或 Derived Classification Registry 字段；
- 不改变现有语义分析和影像分析算法；
- 不新增永久删除、批量文件移动或其他组织操作。
