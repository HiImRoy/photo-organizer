# Plan 0011：将人工标记筛选移入预览底栏

## 目标

参照 Lightroom 的图库筛选条，将星级和色标筛选放在中央图片预览区域底部，而不是放在左侧内容分类面板中。网格预览与单张预览使用同一套横向控件和筛选状态。

## 实施范围

- 从 Sidebar 移除“人工标记”筛选卡片。
- 新增底部“人工标记筛选”横栏，包含星级、色标和清除筛选。
- 网格模式将横栏固定在图片结果区域下方；单张模式将横栏放在主画布和胶片栏之间。
- 继续使用现有 `AssetFilter.ratings` 与 `AssetFilter.colorLabels`，星级字段保存单一阈值并匹配所选星级及以上，不改变人工标记数据模型。
- 保留可访问名称、按下状态和键盘焦点，不增加用户输入框。

## 验收

- 左侧“分类与筛选”不再出现人工标记卡片。
- 网格和单张预览都能看到同位置、同样式的人工标记横栏。
- 星级仍为单选阈值，色标仍支持多选；点击已选星级/色标可取消。
- 横栏不会挤压主图到不可用尺寸，也不会产生页面纵向溢出。
- 前端类型检查、Lint、测试、格式检查和构建通过。
