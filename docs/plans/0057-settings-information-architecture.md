# 0057 设置页信息架构统一

## 状态

已完成。

## 目标

将设置页按用户实际控制的功能划分为“显示”“处理”“快捷键”三类，统一每类中的标题、设置行、选择控件和快捷键输入样式。设置页只展示真实可保存并能生效的选项，不放模型状态、只读并行数或尚未实现的占位配置。

## 信息架构

### 显示

- 主题：深色、白天。
- 启动视图：多图预览、单图预览。
- 默认网格密度：每行 2、4、6、8、10、12 张；仅决定下次启动的初始密度，当前浏览通过 Ctrl + 滚轮即时调整。

### 处理

- 导入：导入并行数 1–2，作用于新导入任务。
- 分析：分析批大小 1–8，作用于新分析任务。
- 分析任务固定单任务串行是运行边界，不作为可编辑设置行展示。

### 快捷键

- 浏览：多图预览、单图预览。
- 星级：清除、1–5 星、增加、减少。
- 色标：红、黄、绿、蓝。

## 视觉与交互规则

- 保留左侧栏目导航与右侧单页内容结构。
- 页面内按功能使用标题和分隔线，不使用嵌套卡片。
- 同类设置行共享高度、标签层级和控件几何规格。
- 快捷键使用统一键帽输入；不使用悬浮、上移和厚重阴影。
- 修改自动保存；“恢复默认”同时恢复主题、启动显示、处理参数和快捷键。
- 深色、白天和窄窗口必须保持同一信息层级。

## 验收

- 三个栏目可以通过键盘和鼠标切换。
- 启动视图和默认网格密度能持久化，并在下一次挂载时初始化浏览区。
- 导入并行数、分析批大小和快捷键继续生效。
- 设置页没有不可编辑的伪设置，也没有重复说明。
- 设置相关测试、前端测试、类型检查、lint、格式检查和生产构建通过。
