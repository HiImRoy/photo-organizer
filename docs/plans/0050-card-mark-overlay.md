# 0050 卡片人工标记浮层恢复

## 背景

卡片上的星级和色标编辑入口曾被移除，导致密集网格只能依赖右侧信息栏或快捷键。旧样式还使用了通用 `:focus-within`，点击图片卡片后会让标记浮层持续显示。

## 本次范围

- 恢复卡片悬停/键盘可见聚焦时的星级和色标浮动编辑层。
- 复用右侧信息栏的星级预览逻辑，悬停第 N 颗星时点亮前 N 颗。
- 保持批量选择语义：已选图片操作时沿用当前选择集合。
- 让浮层在窄卡片中自动换行，且不改变网格轨道高度。
- 仅在卡片悬停或标记控件获得键盘可见焦点时显示；图片卡片获得焦点或保持选中不会固定浮层。

## 验收

- 网格卡片可找到“星级”和“色标”操作组，点击会调用现有标记 API。
- 鼠标点击标记控件后离开卡片，浮层不因普通鼠标焦点继续常驻；只有键盘可见焦点可以暂时保持浮层。
- 2–12 张/行的密集网格中，标记按钮不被裁切，必要时呈两行。
- 既有右侧信息栏、快捷键、筛选和批量标记行为不回归。
