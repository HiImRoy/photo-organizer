# 0054 导入范围与首次启动入口

状态：已实现，待桌面手动验收。

## 目标

- 首次启动空状态改为安静、明确的本地图库入口；
- 将“是否读取子文件夹图片”和“是否建立子图库结构”拆成两个独立选项；
- 保留旧版本默认行为：递归导入子文件夹图片，但不自动建立子图库结构；
- 将导入范围持久化，重新扫描沿用首次导入选择。

## 实现范围

- SQLite migration 0015：为物理图库保存 `include_subfolder_images`；
- Rust 扫描器：关闭时只接受 WalkDir 根深度为 1 的图片，分析仍只消费应用缩略图；
- Tauri IPC/API：增加 `includeSubfolderImages`，重扫读取图库保存的范围；
- 导入确认对话框：第二个“按子文件夹建立图库结构”选项依赖第一个选项；
- 首次启动：以“从一个文件夹开始”为主标题，使用细竖线、少量能力说明和单一主要操作；
- 测试：覆盖默认导入、根目录导入、结构选项禁用和 UI 空状态。

## 验收

1. 默认进入导入确认时，导入子文件夹图片已选中，结构选项未选中。
2. 关闭导入子文件夹图片后，结构选项自动取消并禁用。
3. 三种扫描组合的发现数量、图库数量和重新扫描行为符合选择。
4. 空状态在暗色与浅色主题中均不出现大面积重阴影、孤立卡片或不必要的解释文字。
5. 源文件内容和源目录不会被修改，所有图像分析仍走缩略图路径。
