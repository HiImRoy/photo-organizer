# 0041 左侧筛选栏重排与自适应滚动

## 目标

让左侧导航保持 Lightroom 式的连续工作区层级：图库与筛选是两个可独立滚动的模块，图库高度拖动后不再出现模块内空白；筛选栏把常用的影调/颜色范围放在最上方，把来源放在最下方。

## 决策

- `Sidebar` 负责所有左侧查询维度：顶部为“影调与颜色”，中间为题材、主体、影调、饱和度和日期，底部为当前图库/收藏/集合来源。
- 顶部“筛选”弹层只保留当前已生效条件和清除/移除操作，避免同一查询维度在两个位置重复出现。
- 来源使用与分类相同的扁平导航行，不再增加第三个圆角卡片；来源操作仍只修改统一的 `AssetFilter`，不替换中央工作区。
- 左侧 `grid-template-rows` 的两个直接模块各自填满轨道；图库树和筛选内容区使用 `flex: 1`、`max-height: none` 和独立滚动。

## 验收

- 默认图库和筛选各占左侧可用高度约一半；拖动中间分隔线后，图库内容区随模块高度变化，超出内容在图库区内部滚动，不出现下方空白。
- 筛选栏首个查询区为“影调与颜色”，包含颜色范围、严格程度、亮度范围和饱和度范围。
- 筛选栏最后一个查询区为“来源”，包含当前图库、收藏、虚拟集合和管理集合。
- 顶部“筛选”弹层不再渲染来源或范围编辑器，只显示当前条件。
- 现有来源筛选、颜色范围、亮度/饱和度范围、拍摄日期筛选和现有测试不回归。
