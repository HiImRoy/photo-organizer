# PhotoOrganizer 专业化界面重构计划

- 状态：已完成
- 创建日期：2026-08-07
- 最后更新：2026-08-07
- 范围：仅 React 结构、CSS 视觉系统、前端可访问性测试和 UI 文档

## 目标

将现有新拟物、生活方式化界面重构为专业、克制、高信息密度的桌面图片资产管理工作台，同时保持现有 Tauri IPC、扫描、数据库、缩略图、排序和安全行为不变。

## 假设与边界

- 保留左侧图库导航、右侧主工作区、分页、详情抽屉和现有排序字段。
- 允许为可访问性增加语义化标记、tooltip、选中勾选和结构容器，不改变业务状态或事件流。
- 视觉截图使用开发环境专用、确定性的前端 fixture；fixture 不进入生产构建，不写 SQLite，不触碰个人图库。
- 不修改 Rust、数据库迁移、Tauri command 契约、语义模型接口或文件操作边界。
- 不新增生产依赖、在线字体、外部图片或 UI 框架。

## 风险

- 浏览器预览没有 Tauri IPC，正常图库和扫描状态必须通过明确隔离的开发 fixture 验证；不得影响生产分支。
- 当前仓库所有文件仍为未跟踪状态，Git 无可用基线 diff；本次将结合文件清单、静态搜索、格式化和测试进行自审。
- 详情抽屉为真实悬浮层，允许使用单一中性阴影；其余常规层级只使用背景和边框。
