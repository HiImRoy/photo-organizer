# 0037 色彩筛选严格程度

## 目标

修复色相范围只按固定 8% 命中就通过的问题，并在颜色范围控件中提供可理解的横向严格程度滑块。严格程度越高，选中色相必须占缩略图有彩色区域越高的比例。

## 方案

- 前端 `AssetFilter.colorHueStrictness` 默认 `0.5`，用 0～1 表示用户偏好。
- UI 显示“宽松 / 平衡 / 严格 / 极严”和实际最低命中比例；滑块变化只更新查询，不触发分析。
- SQLite 将严格程度映射为 8%～75% 的最低命中色相占比，继续使用应用私有缩略图生成的 12 桶色相直方图。
- 保留色相环当前范围和跨 0° 的桶选择逻辑，避免本次改动扩大到特征提取或原图预览。

## 验收

- 红橙范围在默认/高严格度下不再因为少量色彩点缀全部通过。
- 0%、50%、100% 严格度分别对应约 8%、42%、75% 阈值，且阈值单调递增。
- 前端组件、色相阈值纯函数和 Rust 查询阈值都有自动化测试。
- 导入、分析和筛选仍不把原图像素送入处理链路。
