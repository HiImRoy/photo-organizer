# M4：图库体验与分类质量优化

## 目标

让日常浏览、选择、单图查看、批量分析和分类筛选具备清晰且可重复的行为，修复主色被中性色覆盖以及原始目录树扁平化的问题。本计划不实现整理预览、复制、移动、重命名或删除。

## 实施范围

1. 重新加权主色分析：从有足够色度的像素中选择代表色，黑/白/灰仅记录为 `neutral_ratio`，并提升暗部/高光中的有彩色权重。
2. 将 TinyCLIP 结果分为稳定的一级分类和辅助场景标签；保留原始相似度与版本信息。
3. 修正目录索引为图库根目录下的完整相对路径祖先集合，前端以完整路径构建可展开树。
4. 采用单击活动图片、Ctrl/Shift 多选、空白/Esc 清除、双击/Enter 单图预览的交互模型。
5. 为单图预览增加缩放、适应窗口、100%、重置、拖动画布和胶片切换。
6. 提供“分析全部”和“分析选中图片”，沿用已有持久化后台任务的暂停/继续/取消和有效结果跳过规则。

## 规则记录

- 一级分类固定为：人像、风景、城市/建筑、静物、动物、文档、其他；模型仍保留夜景、山、水体、森林、花卉、日落、街道等辅助标签。
- 语义分析版本升级为 `photo-organizer-semantic-v2`，因此旧版本标签会被标记为过期并在下一次“分析全部”时重新计算；同一文件/版本的有效结果仍会跳过。
- 一级分类从一级候选中选择最高相似度的一个；辅助标签按阈值和 TinyCLIP 相似度保留，未知仅在没有可接受结果时出现。
- 主色只在加权色度候选中竞争；中性色不参与有彩色竞争，只有有彩色覆盖不足时才返回 `neutral`/黑白灰。
- 目录过滤使用完整相对路径：父目录匹配自身文件或任意后代，路径分隔符不会把同名目录合并。

## 验证

补充 Rust 图像分析、语义分层、目录祖先和路径过滤测试，以及前端选择、预览缩放和批量入口测试；完成 Prettier、ESLint、TypeScript、Vitest、Rustfmt、Rust tests、Clippy 和 production build。
