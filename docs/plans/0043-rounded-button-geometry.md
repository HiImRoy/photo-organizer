# 0043 全局按钮圆角几何

## 目标

消除界面中由后段样式覆盖产生的僵硬方形按钮，建立统一的圆角按钮几何规则；保留圆形勾选和色标作为明确的状态指示器。

## 范围

- 关闭按钮、顶部工具栏、筛选、分页、胶片、卡片操作、状态任务和整理工作区按钮统一使用 `--control-radius`。
- 移除对按钮视觉生效的 `border-radius: 0` 覆盖，不改变结构容器和输入框的平面分隔需求。
- 选择圆点、人工色标和其他明确的圆形状态继续保持 `50%`。
- 规范和视觉验收增加禁止零圆角按钮的约束。

## 验收

- 深色、白天和窄窗口下不出现零圆角的可见按钮。
- 关闭、筛选、工具栏和对话框按钮的高度、圆角和基线统一。
- 选择勾选和色标仍为圆形，不被全局按钮规则改成圆角矩形。
- 相关测试、格式检查、Lint、类型检查和构建通过。
