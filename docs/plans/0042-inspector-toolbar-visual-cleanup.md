# 0042 信息栏与顶部工具栏视觉清理

## 目标

收敛信息栏和顶部工具栏的层级，去除不必要的凹陷、黑色内框和高对比按钮边缘，同时保留左侧筛选栏按钮的描边可读性。

## 范围

- 信息栏导航图只保留所属的单层检查器表面，移除内部地图黑色矩形背景。
- 直方图通道切换使用紧凑、统一的圆角控件。
- 语义分析空结果改为平面文本状态；重新分析操作使用强调色主按钮并靠右。
- 顶部工具栏次要操作在深色和浅色主题中都使用无边缘、无阴影的 Codex 式静默状态，分析操作放到操作组最右侧。
- 左侧筛选栏不参与本次顶部工具栏样式覆盖，继续保留清晰描边。

## 验收

- 右侧导航图内部没有独立的黑色矩形凹槽。
- 直方图 A/L/R/G/B 控件圆角、间距和高度一致。
- 语义分析无结果不再呈现内凹面；重新分析按钮为强调色且不占满整行。
- 两个主题的顶部次要按钮默认看不见硬边，悬停只提供轻微背景反馈；分析按钮位于最右侧。
- 现有测试、类型检查、Lint、格式检查和构建通过；左侧筛选按钮样式回归测试保持通过。
