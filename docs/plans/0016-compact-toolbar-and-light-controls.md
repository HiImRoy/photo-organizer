# Plan 0016：紧凑工具栏与白天模式控件对比度

## 目标

减少顶部工具栏、图片区标题栏和信息栏标题的无效留白，提高图库工作区的信息密度；同时修复信息区滚动时内容阴影压过标题栏的问题，并增强白天模式下按钮的可辨识度。

## 实施范围

- 将应用顶部栏、图库标题栏、信息标题栏和侧栏分区标题统一为紧凑高度。
- 缩小工具栏控件、卡片外边距、详情模块间距和图片底部操作栏的垂直留白。
- 让右侧信息卡的标题与详情滚动区形成明确的隔离层，滚动时标题不被内容覆盖。
- 让左栏、图片区和信息栏之间的分隔缝使用统一底板背景，避免圆角卡片之间出现断开的色带。
- 将“分类与筛选”分区稍微下移，保持图库区与筛选区的层级间距。
- 为白天模式的普通按钮、搜索框、排序控件、分段切换和次要操作增加更清晰的浅灰表面、深色文字和可辨识阴影；主操作继续使用蓝色强调。
- 不改变图片扫描、分析、筛选、选择、预览和导出逻辑。

## 验收

- 顶部栏和图片区/信息区标题栏比当前版本明显更紧凑，工作区可显示更多内容。
- 信息区滚动时“信息”标题始终位于信息卡顶部，不被详情内容或阴影遮挡。
- 白天模式普通按钮、输入框、排序控件和分段切换有清晰的表面边界与文字对比度。
- 深色模式、单图预览、网格预览和整理预览均保持布局稳定。
- 格式检查、Lint、类型检查、测试和构建通过。
