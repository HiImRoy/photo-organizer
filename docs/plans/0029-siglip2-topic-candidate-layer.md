# 执行计划 0029：摄影题材候选层与 SigLIP 2 适配

状态：默认切换与评测工具已实现，真实摄影质量校准待标注集

## 目标

将“拍摄题材”从 Places365 的场景聚类中独立出来，建立可替换的图文候选模型层：

- 题材模型只输出摄影题材候选和相似度，不负责主体检测或环境判断。
- Places365 继续提供场景、室内/室外和叶子证据，不再单独决定摄影师向的题材。
- 当前随包 SigLIP 2 Base 作为默认题材模型，资源通过契约/哈希校验后启用。
- TinyCLIP 与 MobileCLIP-S0 作为可切换的 ONNX 题材模型，分别保留兼容基线和轻量替代路径。
- 题材选择使用每类阈值、候选间隔和未知拒识，禁止强行给出低置信度主类。

## 当前实现范围

1. 增加摄影师向的题材候选定义、提示词模板和稳定 taxonomy 版本。
2. 把当前题材模型的图文匹配结果转换为题材候选；默认 SigLIP 2 使用导出图 logits，替代模型复用同一候选契约；保留原始分数作为证据，不在未评测时强行写入主类别。
3. 在语义结果中区分题材候选与 Places365 场景证据；任务层允许主体模型为人像、动物、车辆、食品和植物提供主类别决策证据，但主体标签仍由 PicoDet/YuNet 独立保存。
4. 更新中文 catalog、详情页模型说明和测试 fixture。
5. 增加模型适配边界文档，不把未安装的模型显示为已启用。
6. 在桌面端增加题材模型选择器；模型切换会更新运行状态、分析任务 provenance 和当前有效语义查询。
7. 为 SigLIP 2 使用导出图中的匹配 logits，为 MobileCLIP-S0 使用图文 embedding cosine，相同 taxonomy 只负责候选层。
8. 评测 CLI 默认使用 SigLIP 2，支持批处理、逐类阈值候选和 margin 扫描；样本不足时不自动改写运行时阈值。

## 题材 taxonomy v2

主要题材继续保持互斥，但只保留画面可观察、适合摄影管理的类别：

- 人像
- 风光自然
- 街拍纪实
- 建筑空间
- 静物产品
- 美食
- 动物与野生
- 植物与微距
- 运动活动
- 文档截图
- 抽象艺术
- 未知（解析层拒识状态，不是模型 prompt）

旅行、商业项目、婚礼、工业项目等不在单张图片上强行推断；它们保留为后续拍摄组/用户确认属性。

## 约束

- 只读取 `grid-640-v1` 缩略图，不读取原图。
- 不新增云端服务或 Python 运行时。
- 不修改原始照片，不写回 EXIF。
- 不把一个模型的结果标记为另一个模型。
- SigLIP 2 资源已进入本地开发/打包资源并设为默认；提示词已按官方 64-token 模板协议修订，分析版本已提升；正式发布前仍需在真实摄影样本上完成逐类阈值校准，并继续完成许可证审核。

## 验收标准

- 题材候选与主体/环境标签不会互相覆盖或重复写入。
- 候选模型缺失时，应用仍可启动并明确显示基线/未启用状态。
- 低分或候选间隔不足时产生虚拟未知，不产生伪造主类。
- 题材候选、阈值、模型版本和 taxonomy 版本可追踪。
- 模型选择器可分别装载 SigLIP 2 Base INT8 和 MobileCLIP-S0 INT8，并在同一 fixture 上完成无失败推理。
- Rust 测试、前端测试、lint、类型检查和构建通过。
- 质量校准只有在每类正负样本达到最低数量、人工复核混淆矩阵并确认 unknown/coverage 取舍后，才可将候选阈值写回运行时。
