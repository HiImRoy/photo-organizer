# 0062 GPU 性能 S2：批处理校准与运行时自适应

状态：S2.1/S2.2 已完成；S2.3（长图库与实时显存诊断）待后续

## 本轮实现与校验结果（2026-08-26）

- DirectML 初始有效批大小由选定适配器的专用显存分级计算：小于 2/4/6/8/12/16 GiB 分别使用 2/4/8/12/16/24，16 GiB 及以上最多 32；CPU 始终不超过 8。
- 语义题材和主体批处理失败时，使用相同后端、相同应用缩略图递归减半；最终单图重试仍不会打开原图。
- semantic-benchmark 只接受 grid-640-v1 应用缩略图，并记录实际 selected backend、warm-up、实测批次数、失败批次数、延迟和吞吐。
- 仓库隔离测试图库 3 张：CPU 实际后端为 cpu、吞吐约 3.187 张/秒；DirectML 实际后端为 direct_ml、吞吐约 7.192 张/秒；两者失败均为 0。该结果只代表本机小样本，不代表所有设备。
- 尚未接入实时 DXGI 视频内存预算/峰值显存统计，也没有据此宣称某个批大小对所有显卡最优。

## 明确不在本次范围

- 不增加 CUDA、Python sidecar、远程服务或新的生产依赖。
- 不把 WebView2 合成 GPU 与 ONNX 推理 GPU 混为同一个开关。
- 不在没有真实基准数据前宣称某个批大小对所有显卡最优。
