# Plan 0013：信息单层凹面与侧栏模块层级强化

## 目标

让右侧信息面板的文件、拍摄信息、人工标记、影调色彩、分类和语义模块统一呈现为“外层圆角模块 + 单层凹面内容井”；导航图和影调色彩不再连续凹陷。同时把左侧“图库”和“分类与筛选”拆成两个独立的圆角矩形模块，并改善图库节点与标题栏之间的呼吸空间。

## 实施范围

- 新增右侧信息模块的表面令牌：模块容器使用一次浮起层，分析指标、分类编辑区域和预览导航图使用一次凹面内容井，避免双重内凹。
- 保留信息标题、模块标题、状态文字、键盘焦点和人工标记的可识别对比。
- 将左侧“图库”和“分类与筛选”放入两个独立的圆角矩形模块；模块内部的筛选组保持扁平，避免额外叠加浮起卡片。
- 将左侧顶部可见标题从“资料库”统一改为“图库”。
- 增强“图库”和“分类与筛选”标题栏的亮度、阴影和底部层级，不增加无意义的硬边框。
- 增加图库树与顶部标题栏之间的固定留白，不改变侧栏滚动和图库数据。

## 验收

- 右侧信息模块的外层为圆角浮起面，导航图和分析指标各自只凹入一层，不出现连续两次内凹。
- 左侧“图库”和“分类与筛选”是两个一眼可分开的圆角矩形模块，两条标题栏清晰，图库节点与“图库”标题之间有明确但不过量的留白。
- 不改变按钮行为、图片查询、拖拽、预览或数据模型。
- 前端格式检查、Lint、类型检查、测试和构建通过。
