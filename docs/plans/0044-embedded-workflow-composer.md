# 0044 嵌入式查找与审阅工作区

## 目标

把查找与审阅从“覆盖在图库上的独立界面”收敛为中央画布下方的可调整工作区，并让本地语义搜索拥有简洁、可读、真实可提交的输入容器。

## 范围

- 移除顶部工具栏重复的“导入”和主题切换；导入保留在图库标题栏，主题保留在设置页。
- 在图库和查找与审阅之间增加无障碍水平分隔条，支持指针拖动、键盘上下方向键和 `aria-valuenow`。
- 将嵌入式工作区的高度限制在 250–640px，默认 360px；高度变化只影响布局，不重新查询或触碰原图。
- 将本地 AI 搜索输入改为低对比度、低阴影的 Codex 式 composer，保留真实文本输入和提交动作，不添加无功能的装饰控件。

## 验收

- 顶部“图库操作”组不再出现“导入”“白天/深色”，图库标题栏仍能导入，设置页仍能切换主题。
- 打开“查找与审阅”后，可以拖动中央分隔条改变其高度；分隔条可被键盘聚焦并用上下方向键调整。
- 搜索框在深色和白天主题下都具备清晰的输入焦点、提交按钮和占位文本；不出现大范围阴影或大幅上浮动效。
- 相关测试、格式检查、Lint、类型检查和构建通过。
