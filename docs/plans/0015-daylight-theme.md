# Plan 0015：白天模式主题

## 目标

为 PhotoOrganizer 增加可切换、可持久化的浅色白天模式，同时保持当前深色模式为默认主题。

## 实施范围

- 顶部工具栏增加“白天 / 深色”主题切换按钮，并提供完整的无障碍名称和提示。
- 通过主题令牌统一浅灰背景、卡片、按钮、输入框、图片画布、信息面板和滚动条的层级。
- 保留低饱和灰蓝作为选中、焦点和主要操作强调色；人工色标继续使用其语义颜色。
- 使用本地存储记住用户选择；浏览器存储不可用时仍可正常切换但不持久化。
- 不改变图库、图片分析、筛选、预览和导出业务逻辑。

## 验收

- 默认打开仍为深色模式。
- 点击“白天”后，工作区、侧栏、图片区域和信息区域全部切换为有层次的浅色表面。
- 点击“深色”可恢复当前深色界面；刷新后保留上次选择。
- 图片、选中状态、焦点状态和人工色标在两套主题下仍清晰可辨。
- 前端格式检查、Lint、类型检查、测试和构建通过。
