# 0046：移除图片卡片人工标记浮窗

## 目标

让网格卡片只承担浏览、选择、收藏和打开预览，不再在鼠标悬停时弹出星级/色标编辑层。人工标记统一收敛到右侧信息栏和已存在的键盘快捷键，顶部人工标记筛选仍保留。

## 实施范围

- 删除 `AssetCard` 内的星级和色标编辑控件及相关回调接口。
- `GridWorkspace` 不再向卡片传递人工标记写入回调。
- 保留 `DetailPanel` 的人工标记编辑器、批量选择语义和键盘快捷键 `1–5` / `6–0`。
- 保留卡片已有标记的非交互状态样式，不因移除编辑入口改变卡片高度。
- 更新 UI 规范，明确卡片不是人工标记入口。

## 验收

- 图片卡片内不存在星级按钮、色标按钮或人工标记浮层。
- 选中图片后，右侧信息栏仍能修改星级和色标。
- 单图预览中快捷键仍能修改星级和色标，批量选择时仍作用于选择集合。
- 顶部人工标记筛选仍能按星级和色标筛选。
- 变更不触碰原图，也不改变缩略图优先的导入、分析和预览加载链路。
