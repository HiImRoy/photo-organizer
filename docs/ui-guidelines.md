# PhotoOrganizer 界面设计规范

## 方向

界面是深色、桌面优先的专业摄影工作台，结构参考 Lightroom 类图片管理软件但不复制品牌、图标或像素细节。图片始终是视觉主体。

扁平化桌面工作台是本阶段的整体视觉语言：以图库、暗房、胶片带和检查器为视觉语境，使用连续的侧栏、中央画布、右侧信息栏、适度圆角、分割线、缩进和明确的文字层级表达结构。圆角用于表达工作区容器、图片卡片和输入控件的归属，但必须克制并保持统一；取消新拟物高光、内外双层阴影、渐变和大面积发光。描边只保留给键盘焦点、当前图库、当前图片、选中图片、拖拽目标和人工色标等需要快速识别的状态。人工色标只在图片卡片网格单元使用低饱和度背景和对应色提示，不给原图加色，也不承担唯一的状态表达。禁止通用 SaaS 卡片堆叠、无语义胶囊按钮、装饰性数字徽标和依赖颜色才能理解的状态。

## 设计 token

全部 token 统一维护在 `src/styles.css`：

- 深色应用/画布：`#191919` / `#202020`
- 深色工具栏/面板：`#242424` / `#2B2B2B`
- 浅色应用/画布：`#F7F7F5` / `#F0F1F1`
- 浅色工具栏/面板：`#FFFFFF` / `#E8E9E8`
- 灰阶层级：`--surface-0` 画布、`--surface-1` 侧栏、`--surface-2` 面板、`--surface-control` 悬停/选中；层级优先使用背景差和留白，边界只使用低对比度分割线。
- 边框：普通表面使用 `--line-subtle` 的 1px 分割线；状态/焦点使用低饱和灰蓝或对应色轮廓。
- 主/次/弱文字：`#EEEEEE` / `#C1C1C1` / `#898989`
- 单一灰蓝强调：`#9EB5C1`，强强调 `#C7D6DC`，仅用于选中、焦点和主要操作
- 圆角：工作区容器 12–14px、图片卡片 10–12px、普通控件 7–9px、浮层 10–14px；禁止 999px 胶囊式主操作
- 控件组：同一操作组共享高度、内边距节奏、边框厚度、圆角和间距 token；主/次按钮只能通过颜色和强调等级区分，不能出现相邻方形/圆形或高低错位
- 紧凑操作组默认使用 `--control-height-compact`、`--control-radius` 和 `--control-group-gap`，如需不同尺寸必须由整个操作组共同切换；可见按钮禁止使用零圆角的僵硬方形，圆形只用于明确的选择/色标状态
- 字体：`Segoe UI Variable Text`，中文回退 `Segoe UI`、`Microsoft YaHei UI`、`PingFang SC`

不得添加在线字体或大型 UI 框架。正文、边框、键盘焦点必须保持可辨识对比。

## 工作区结构

- 最左侧 44px 工作区竖栏（窄桌面依次收窄到 42px、40px）：用房子和书本线稿分别进入图库、整理预览；设置位于竖栏底部。导航按钮在常规桌面统一使用 40×40px 触控区域和 20×20px 图标画布，窄桌面按轨道同步缩小；图标路径必须按视觉中心校准，不能因图形自身留白造成左右偏移。竖栏本身透明、无右侧硬分割线，只负责工作区切换，不承载筛选、导入或批量操作。工作区外层使用统一的板块间距 token，竖栏仍保持轻量，不额外制造第三个圆角容器。
- 顶部 64px 工具栏：图库名称、数量/扫描状态、网格/单图切换、搜索、筛选、排序和分析；导入入口固定在“图库”标题栏，主题切换收纳到“设置”，工作区入口不再重复放在右上角。
- 左侧默认 270px：上方独立的“图库”区域承载 Library 树，“新建/导入图库”入口固定在“图库”标题栏右侧，图库节点保持紧凑行距；首次启动的空状态使用安静的工作台入口，明确本地处理、只读索引和选择文件夹，不使用孤立的大卡片或装饰性营销文案。只有一个图库时不再额外显示重复的“图库”标题。下方独立滚动的“筛选”区域首个查询区为“影调与颜色”（颜色范围、严格程度、亮度和饱和度范围），中间承载内容属性筛选，最后一个查询区为“来源”（当前图库、收藏和虚拟集合）。图库与筛选默认各占左侧可用高度的一半，中间分隔线可上下拖动调整，两个区域始终独立滚动。未完成语义分析的状态筛选移到中央图片区域上方。面板始终显示，宽度可在 218–420px 之间拖动调整。图库树只展示 PhotoOrganizer 中显式建立的 Library 关系，不展示磁盘目录树。
- 中央：顶部一条扁平结果工具栏承载数量、当前筛选摘要、靠左的人工标记筛选、每行图片数滑块、“分组”下拉框和分析状态；人工标记筛选不显示重复标题，不占用图片结果底部。多图模式按每行 2–12 张、每次 2 张的离散刻度调整网格；`Ctrl + 滚轮`向上减少两列、向下增加两列。下方是网格、可逐组折叠的分组网格、单图画布和连续滚动加载结果；工具栏与中央工作区齐平，不再嵌套额外圆角面板。卡片只显示文件名、少量传统指标和最多两个标签。
- 右侧默认 320px：文件、EXIF、影调色彩、语义相似度、模型/后端和重新分析；面板始终显示，可在 256–460px 之间拖动调整。
- 整理预览使用三栏规划工作区：左侧编辑范围、目录维度和命名规则，中间显示目标目录树与逐文件映射，右侧检查选中映射的路径、模板变量和问题；生成前用简短三步空状态引导，不用大面积无信息留白。
- 整理目录维度行必须明确分开“按什么分目录”和“缺失时怎么处理”；日期维度才显示文件修改时间回退，非日期维度不得暴露无效的修改时间选项，并在行下给出一个简短示例。
- 查找与审阅中的重复、相似、比较和编辑等工具作为中央画布下方的嵌入工作区显示，不再成为独立全屏页面；工作区上缘提供无障碍水平分隔条，可用鼠标拖动或上下方向键调整高度，且不改变图库查询结果。自然语言搜索使用一个真实可提交的低干扰输入容器，不添加无功能的附件、麦克风或装饰性 AI 控件。
- AI 搜索从中央结果工具栏的“AI 搜索”按钮打开时，输入框固定在中央画布下缘的悬浮工作面上，不再占用图库高度；图库保持可见，检索结果在输入框上方的有限高度区域内滚动展示，关闭后恢复纯图库视图。
- AI 搜索结果卡片必须与主图库共享当前图片、批量选择、星级和色标逻辑：缩略图单击只聚焦当前图片，圆形选择控件单独负责勾选；双击结果关闭搜索浮层并回到原图库定位当前图片，不改变批量选择集合。
- 右侧检查器中的导航图、直方图和语义空状态直接使用检查器表面；导航图不再套黑色内框，语义空状态不使用凹陷输入框样式。直方图通道切换保持统一的紧凑圆角规格。
- 左右面板靠近中央画布的分隔边缘承担宽度调整；边缘提供一条低对比度的短竖向拉手，悬停或键盘聚焦时才强调，避免把分隔条误认为第三个面板。左侧图库与筛选之间的水平分隔线承担高度调整。拖动只改变布局尺寸，不改变图库、图片或源文件数据；键盘仍保留可访问的分隔条语义。
- 单图模式底部固定紧凑胶片栏；网格模式不显示。单图选择入口固定在中央结果工具栏最右侧，使用一个空心/带勾的圆形状态按钮，不在画布角落再放文字选择框。
- 人工标记筛选横栏在网格和单图模式都位于中央顶部结果工具栏；两种视图共用同一组星级与色标筛选状态。

宽度 1260px 以下左右面板收窄，1080px 以下工具栏次要操作只保留图标。960×720 是较窄桌面兜底；用户可拖动圆角面板外缘释放或恢复画布空间。页面本身不得横向溢出。

## 状态与语义

- 当前图片同时使用蓝色边框、勾选和 `aria-pressed`，不只依赖颜色。
- 单图预览的“选择/取消选择”固定在画布左上角，使用一个统一高度的大圆角矩形；内部勾选状态使用圆形指示器，不能退化为方形复选框。结果工具栏的人工标记筛选紧跟数量摘要，减少无意义的横向留白。
- 图片被选中或作为当前图片时，强调描边必须连续包围整张卡片外壳，覆盖缩略图、文件信息和人工标记区；不得只显示在卡片下半部分，也不得被内部容器裁剪。
- 单图模式必须保留当前图片的“选择/取消选择”入口；入口固定在结果工具栏右侧，胶片栏同时区分当前图片和选择集合，避免只导航图片却无法参与批量操作。
- 图片卡片在鼠标悬停或人工标记控件获得键盘可见焦点时显示紧凑的星级/色标浮动编辑层；鼠标点击产生的普通焦点不会把浮层固定打开。选中状态只保留整卡描边，浮层不改变网格轨道高度，窄卡片允许自动换成两行，并在鼠标离开卡片后收回。
- 星级标记和星级筛选共用同一预览逻辑：鼠标或键盘聚焦第 N 颗星时，前 N 颗同时点亮；点击才提交 N 星，移出后恢复当前值。
- 人工标记筛选作为中央顶部结果工具栏中的紧凑控制区提供，不嵌入左侧分类面板，也不在底部单独占用一条面板；星级为单一“该星级及以上”阈值选择，色标支持多选，清除入口只在存在筛选时出现。
- 左侧筛选按钮采用紧凑圆角矩形行；保留清晰的文字、计数、悬停、按下和选中状态，避免单个计数变化导致模块高度跳动。图库存在未完成语义分析时，中央图片区域上方显示紧凑的“分析状态”筛选条；没有未完成分析时不占用空间。
- 色标生效时，网格单元仅使用低饱和度的对应背景/边框提示；缩略图本身保持原样。批量选择后从任意选中卡片操作，会同步应用到整个选择集合。
- 按钮必须有明确的浮起、悬停、按下、选中、禁用和键盘焦点状态；按下时使用内阴影和轻微下沉，悬停时只允许轻微抬升。
- 动效必须按层级使用：图片卡片最多 2px 的轻微位移，主要按钮优先使用颜色变化；次要按钮、筛选项和导航项不得统一上浮。悬停阴影使用短距离、低透明度的柔和阴影，曲线统一使用 `cubic-bezier(0.25, 1, 0.5, 1)`，并遵守减少动态效果设置。
- 桌面工作区禁止浏览器默认右键菜单；图片、卡片、面板和画布区域不得出现“复制图像/检查/刷新”等网页命令。搜索框、文本框和可编辑区域可保留原生编辑菜单。
- 相邻按钮属于同一操作组时必须使用同一几何规格：高度、基线、内边距、边框厚度、圆角和间距一致；主次样式只改变颜色/强调，不改变形状。设置页底部“恢复默认/完成”是该规则的固定示例。
- 弹窗和选项组只保留完成当前操作所需的文字：标题、对象/路径、控件标签和操作按钮；不要同时用副标题、控件说明、状态复述解释同一件事。只有会导致误操作的条件依赖才保留一行简短提示，常规行为由控件名称、禁用状态和焦点反馈表达。
- 普通按钮、筛选芯片和模块不应通过成片的 1px 亮边分隔；同一层级优先共享表面色和阴影，避免“每个元素都有一圈线”。
- 可变的筛选计数徽标必须预留固定尺寸；从未选中到选中只改变内容和可见性，不得改变分类模块高度或推动下方模块。
- 语义分值必须写“相似度”，右侧明确说明不是概率或准确率。
- 模型未就绪时不显示假标签；按钮显示准备模型，基础图库保持可用。
- 任务条显示真实 processed/total、失败数和实际 backend，并提供暂停/继续/取消。
- 错误使用文字与 `role=alert`；进度使用原生可访问名称和数值。

## 视觉验收

检查 1920×1080、1440×900、1366×768 和 960×720：

- 页面 `scrollWidth` 不大于 viewport，工具栏不横向溢出；
- 网格列稳定变化，长中文/Unicode 文件名省略；
- 左右面板始终显示，内容区域独立滚动；
- 左侧图库区与筛选区使用两个明确的导航模块并分别滚动；影调与颜色范围放在筛选栏顶部，来源筛选在筛选栏底部以紧凑来源行提供，模块内部筛选组保持轻量，避免卡片堆叠；左右面板靠近中央画布的分隔边缘可拖拽，最小/最大宽度生效；
- 右侧信息模块使用单层柔和容器：标题、导航图、直方图和信息行共享同一检查器层级，不叠加相同的内阴影；
- 右侧检查器只能有一个外轮廓，内部标题、预览、直方图和信息段落使用平面分隔，禁止再次嵌套相同的圆角矩形；
- 浅色主题的直方图必须使用可辨识的中性底、网格和 RGB 描边/填充，不能依赖低对比度的浅色填充；
- 顶部工具栏不提供主题切换；主题在“设置 → 主题与显示”中修改。白天模式使用浅灰层级而非纯白，蓝色只承担选中、焦点和主要操作语义；人工色标保留其原有颜色。
- 顶部工具栏只保留浏览控制与当前图库的分析动作；整理预览和设置通过最左侧竖栏进入，AI 搜索使用中央结果工具栏中的“AI 搜索”按钮，避免把工作区导航摊平在右上角。
- 顶部工具栏的次要操作默认采用无硬边、无阴影的静默按钮，仅在悬停或选中时改变表面色；主要“分析”操作使用强调色并位于图库操作组最右侧。该规则只适用于顶部工具栏，左侧筛选按钮仍保留可读描边。
- 查找与审阅的高度分隔条默认保持安静，仅在悬停或键盘聚焦时显示细微强调线；拖动增加或减少工作区高度时，不使用上浮、弹跳或大范围阴影。
- 多图网格缩放属于结果工具栏的低干扰离散控制；滑块按 2、4、6、8、10、12 张/行调整列数，`Ctrl + 滚轮`每次改变两列，只在图片网格内改变密度，不触发浏览器页面缩放或原图解码。
- 左侧图库区与筛选区默认各占一半高度，树行保持高信息密度；拖动两区之间的水平分隔线可调整比例，图库树和筛选内容区都随轨道伸缩并独立滚动；筛选区顶部为影调与颜色，底部为来源，不在顶部弹层重复编辑。
- 左侧“图库”和“筛选”各自只拥有一个外轮廓，内容区透明铺开；左侧结构容器本身不再增加第三个边框、背景或阴影，不在模块内部再套相同的圆角卡片；颜色范围和影调范围固定在左侧筛选栏顶部，来源固定在左侧筛选栏底部。
- 三栏工作区的外侧页边距由工作区容器统一承担；除左侧“图库”和“筛选”之间保留原有的紧凑高度拖拽区外，中央图库、右侧信息、任务条和整理/审阅等圆角板块统一使用 `--workspace-panel-gap`，与相邻边缘保持稳定间距。左侧两个模块不再叠加第二层外留白，模块外边缘仍与工作区轨道对齐。
- 筛选使用等宽的紧凑矩形导航单元，标签保持左对齐、计数固定右对齐；选中态使用单条强调线和浅色底，不使用散乱的胶囊标签。
- 图片卡片支持悬停/键盘可见聚焦的人工星级与色标浮动编辑层，右侧信息栏与快捷键仍可完成同一操作。鼠标点击控件后移出卡片，浮层必须收回；窄列时可换行且不得改变网格卡片高度。
- 中央结果工具栏按中央画布自身宽度响应：宽度不足时按“摘要与操作 / 标记与缩放”分行，极窄时再将分析状态独立成一行；各行之间使用明确间距，禁止按钮、下拉框和状态点互相覆盖或压缩到不可读。
- 人工标记筛选横栏在网格和单图预览中都位于中央顶部结果工具栏，且不进入左侧分类面板；
- 单图画布和胶片栏同时可见；
- 组合筛选后的数量、卡片和分组结果一致；分组下拉框可切换拍摄题材、主体标签、影调、饱和度级别、主色和评分，切换时不重新查询；每个分组标题可独立展开/折叠，只改变该组预览网格的可见性，不触发重新查询。
- 键盘焦点、空/加载/扫描/错误/模型不可用状态清晰。
- 设置作为独立的轻量对话层进入，采用左侧栏目导航、右侧单页内容的 Codex 式工作区结构；界面、性能、快捷键互不堆叠，快捷键页再按视图、星级、色标和星级调整分组。
- 同一操作组的相邻按钮不得出现方圆混用、高度不同、基线错位或间距不一致；必须在深色、白天主题和窄窗口下复核。
- 所有可见按钮（包括关闭、图标、工具栏、筛选、分页、胶片、卡片、整理和对话框按钮）必须使用统一圆角控件几何；不得通过 `border-radius: 0` 制作方形按钮。圆形仅保留给选择勾选和色标等明确的状态指示器。
