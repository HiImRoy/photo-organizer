# PhotoOrganizer 当前功能与界面说明

> 文档状态：基于当前 `main` 分支代码整理。
> 适用版本：`package.json` 中的 `0.1.0`。
> 运行形态：Tauri 2 桌面应用；Vite 浏览器预览仅用于界面验收。

## 1. 产品定位

PhotoOrganizer 是 Windows 优先、本地优先的照片管理工作台。它把“图片的虚拟分类结果”和“磁盘上的真实目录结构”分开保存：用户可以扫描、分析、筛选、预览图片，并生成整理目录与文件名的只读计划，但正常浏览和分析不会修改原始照片。

当前代码的核心原则如下：

- 只扫描用户明确选择的根目录，递归识别 JPEG、JPG、PNG 和 WebP，扩展名不区分大小写。
- SQLite 保存图库、资产、扫描任务、缩略图索引、传统特征、语义结果和整理预览计划。
- 缩略图、屏幕预览、模型和日志保存在应用数据目录，不写回源图库。
- 单张图片分析失败不会终止整次扫描或语义任务。
- 扫描和语义分析在后台运行，并通过进度事件更新界面。
- 当前没有移动、重命名、覆盖或删除源文件的执行入口；图像编辑只允许在预览计划确认后创建一个全新的派生副本。
- “整理预览”是 dry-run：只生成源路径到规划目标路径的映射；导出 JSON/CSV 是唯一由用户明确触发的文件写入。

## 2. 当前实现范围与运行模式

### 2.1 Tauri 桌面模式

桌面模式由 Tauri 承载 React/TypeScript 界面，Rust 负责：

- 目录遍历、文件 fingerprint 和增量扫描；
- EXIF/基本元数据读取；
- 缩略图和屏幕预览生成；
- 亮度、对比度、饱和度、色度、主色和中性色比例分析；
- SQLite 初始化、迁移、筛选、排序、分组和任务持久化；
- 随包 TinyCLIP INT8 + ONNX Runtime 的本地 CPU 语义分类；
- 整理规则校验、目标路径规划、冲突诊断和清单导出。
- 收藏、虚拟集合、精确重复分组、本地文本/以图搜索、相似聚类和非破坏性编辑副本。

前端通过类型化 Tauri command/response 和 `scan-progress`、`semantic-progress` 事件与 Rust 通信。应用不开放远程后端或网络服务。

### 2.2 Vite 浏览器预览模式

开发服务器可以使用确定性的视觉夹具，不读取 SQLite、不打开系统目录选择器、不访问个人照片：

```text
http://localhost:1420/?visual-fixture=library
http://localhost:1420/?visual-fixture=scanning
http://localhost:1420/?visual-fixture=error
```

浏览器预览可以体验图库、筛选、排序、选择、详情、单图预览和扫描/语义任务的视觉状态。需要桌面能力的操作会被禁用、返回空结果或显示“仅在桌面应用中可用”，例如真实导入、真实扫描、真实模型准备、重新分析和 Explorer 操作。

## 3. 功能总览

### 3.1 建立与维护图库

1. 首次启动显示“建立本地图片库”空状态。
2. 点击导入后，通过系统目录选择器选择根目录。
3. 导入确认对话框默认关闭“导入子文件夹结构”；关闭时根 Library 递归扫描全部图片，但不创建子图库节点。开启时，根目录始终建立一个 Library，每个直接包含 JPEG/JPG、PNG 或 WebP 的子文件夹建立独立 Library，空文件夹不建立节点。
4. 开启结构导入时，首次层级按 SourcePath 的物理嵌套关系初始化；这只是默认关系，后续手动拖放的 `parentLibraryId` 会持久保留。
5. Rust 后台按 ownership scope 扫描；父 SourceRoot 会剪枝已导入的物理嵌套 SourceRoot，子图库由自己的 scope 扫描，不会被父图库隐式重扫。
6. 扫描阶段记录发现、处理、成功、失败、跳过和缺失数量。
7. 扫描完成后将本轮未发现的既有资产标记为缺失；扫描取消不会把尚未遍历的文件误标为缺失。
8. 重复扫描按库内绝对路径和 fingerprint 增量更新；源文件大小或修改时间变化会使相关缓存/分析结果失效。
9. 图库菜单支持重新扫描、在资源管理器中显示、查看图库信息、移出当前父图库和从 PhotoOrganizer 索引中移除。
10. “从图库移除”只清理应用索引、分析结果、任务和应用缓存，不删除或修改源文件。

### 3.2 元数据、缩略图和传统图像分析

扫描后资产可保存并展示：

- 文件格式、大小、修改时间、相对路径；
- 宽度、高度和方向；
- 拍摄时间；
- 相机品牌/型号、镜头、曝光时间、光圈、ISO、焦距等常见 EXIF 字段；
- 应用私有缩略图；
- 亮度、对比度、饱和度、色度；
- 影调等级：低调、均衡、高调；
- 主色十六进制值、主色类别、彩色主色覆盖率、中性色比例；
- 饱和度等级和分析完成/失败状态。

导入时每张图片只生成一份不超过 `640×640` 的应用私有缩略图；亮度、对比度、饱和度和主色等基础特征从同一份缩略图像素缓冲区采样计算。缩略图缓存和基础分析使用显式版本，旧版本缓存会在重新扫描时失效重建。不超过 32MB 的源图在导入阶段一次读入，同时复用完整内容 fingerprint 和解码字节；更大的源图仍采用受内存约束的流式 fingerprint。

缩略图用于网格和胶片栏；单图预览打开时直接读取当前图片原图，原图读取失败时才回退到屏幕尺寸预览。请求使用 generation token，切换图片时会忽略旧请求，不会把预览资源写回原图库。

### 3.3 浏览、筛选、排序和分组

图库支持：

- 文件名或路径搜索；
- 原始目录前缀筛选；
- 语义标签筛选；
- 语义标签“任一标签”或“同时包含”匹配；
- 尚未语义分析、分析失败快捷筛选；
- 影调筛选；
- 主色类别筛选；
- 人工星级筛选（选择一个星级阈值，匹配该星级及以上）；
- 人工色标筛选（红、黄、绿、蓝、紫）；
- 亮度范围和饱和度范围筛选，范围为 0 到 1；
- 拍摄日期起止筛选；
- 按文件名、拍摄时间、修改时间、亮度、饱和度排序；
- 升序/降序切换；
- 按一级语义标签分组；
- 分页浏览，前端当前页大小为 120，实际查询由 SQLite 层完成。

组合筛选会在顶部显示已应用筛选数量，并提供“清除筛选”。文件夹、标签和数值筛选可以叠加。

### 3.4 语义分类

语义分类使用随应用分发的 TinyCLIP INT8 模型，在本机 ONNX Runtime CPU 后端执行。结果保存：

- 标签 ID 和中文显示名；
- 原始相似度和阈值；
- 模型名称、模型版本、分析版本；
- 分析时间、来源 fingerprint；
- 一级分类/辅助标签标记。

当前对用户开放的语义标签目录包含：主类别为人像、风景、建筑、静物、动物、文档、未知；辅助标签为多人、室内、街道、车辆、食品、夜景、花卉、抽象。历史记录中的静物、截图、山、水体、森林和日落仍可显示，但不再作为新的选择项或自动结果。

主类别用于主分组和筛选；辅助标签单独用于多标签筛选。两者不再混合显示，也不共享同一组选项。

语义状态包括模型未就绪/不可用、排队、运行、暂停、取消中、完成和失败。模型不可用时，基础图库、缩略图、传统影调色彩分析仍然可用，界面不会伪造语义标签。

### 3.5 图片选择与预览

网格中的图片支持：

- 单击激活图片并在右侧显示详情；
- 点击卡片左上角选择/取消选择；
- Ctrl/Command 点击进行多选或反选；
- Shift 点击选择连续范围；
- 双击进入单图预览；
- 选中图片后按 Enter 进入单图预览；
- 网格空白区域点击清除批量选择；
- Esc 清除选择，或在单图模式返回网格。

单图模式提供胶片栏、按当前筛选和排序结果导航、右侧信息面板中的 Lightroom 风格 Navigator、高清预览、Fit/25/50/100/200/400/800/1100% 缩放、滚轮连续缩放、主画布中心基准缩放和放大后的拖动画布。缩放阶梯还支持 6.25% 和 12.5%，不以 25% 或 400% 作为边界；最高 1100% 对齐 Lightroom Classic 的 11:1 级别。

### 3.6 整理预览 Dry-run

“整理预览”用于在真实文件操作前审查目标目录和命名计划。用户可以：

- 选择当前筛选结果、全部图片或用户选中图片作为范围；
- 输入或选择目标根目录；
- 添加、删除、拖动和上下移动目录维度；
- 为每一层目录设置缺失值回退策略；
- 编辑命名模板；
- 设置缺失元数据策略；
- 设置重名策略：添加序号、添加 short hash、跳过；
- 设置序号起点和序号宽度；
- 生成目标目录树和逐文件映射；
- 查看文件数、冲突数、错误数、警告数和预计字节数；
- 点击单条映射查看源路径、规划目标路径、模板变量和问题；
- 导出 JSON 或 CSV dry-run 清单。

规划器会检查源缺失、源文件变化、缺失元数据、非法路径段、Windows 保留名、路径过长、目标越界、重复目标和已存在目标等问题。目标根目录不会被创建，不能位于源图库内部；当前版本没有执行复制按钮。

### 3.7 智能工作台与非破坏性编辑

顶部“智能工作台”提供八个相互独立但复用当前图库选择的工作流：

- **收藏**：独立于 0–5 星评分的布尔标记；收藏与星级互不覆盖。
- **集合**：多对多虚拟分组，可把当前多选图片加入或移出集合；删除集合不删除图片。
- **AI 搜索**：TinyCLIP 在本机编码任意文本，使用当前模型/版本/fingerprint 的 512 维图片向量做精确余弦检索；常见中文主题词先在本地映射为模型提示词。
- **重复清理**：按完整内容 BLAKE3 分组，优先建议保留收藏或高星图片；“清理”只生成“重复待处理”审阅集合，不删除、移动或改名原图。
- **相似聚类**：单图相似搜索使用精确余弦；图库聚类按向量主维度召回候选、精确复核并用 complete-link 约束拆分桥接组。
- **比较**：复用当前多选，支持 2–4 张屏幕预览并排比较和共享的适应/填充模式。
- **图像编辑**：支持 90° 旋转、水平/垂直翻转、中心方形裁剪、曝光、对比度和饱和度；预览和最终导出使用同一 Rust 配方实现。
- **人物**：提供默认关闭的隐私状态、模型许可门禁和一键清空派生数据。当前安装包没有经产品许可审核的人脸检测/识别权重，所以不会执行人脸身份聚类，也不会回退到云端或伪造结果。

编辑导出必须先选择目标并生成计划。计划拒绝图库根目录内的目标、已存在目标和不支持的扩展名；执行前重新计算源文件 BLAKE3，先写文件操作日志，再用 `create_new` 创建 JPEG/PNG/WebP 副本。新副本支持“预览撤销”：只有目标仍存在且 BLAKE3 与操作日志一致时才允许删除，哈希已变化则拒绝回滚。任何情况下都不会写回或覆盖原图。

## 4. 主界面布局

主界面由顶部工具栏、左侧图库/分类区、中央工作区和右侧信息区组成；左右圆角面板的外缘就是可拖拽的宽度调整区域，不再显示独立的宽度拖手：

```text
顶部工具栏
┌──────────────────────────────────────────────────────────────┐
│ 图库身份/统计 │ 视图 搜索 筛选 排序 导入 语义 智能工作台 整理预览 │
├───────────────┬──────────────────────────────┬───────────────┤
│ 左侧：图库     │  中央网格 / 单图 / 整理预览  │ 右侧图片详情   │
│   拖圆角边缘   │  人工标记筛选横栏            │   拖圆角边缘   │
│      分类筛选  │  胶片栏（仅单图模式）        │                │
└────────────────┴──────────────────────────────┴────────────────┘
```

左侧上方是独立的“图库”区域，下方是独立滚动的“分类与筛选”区域；图库树过长不会把分类筛选推到窗口外。左右面板始终保留，直接拖动圆角面板靠近中央画布的外缘即可调整宽度，避免额外的折叠按钮和可见拖手占用界面空间。

| 低调/均衡/高调      | 始终显示           | 按影调等级进行多选筛选。                                                                                                                   |
| 主色圆点            | 始终显示           | 按红、橙、黄、绿、青、蓝、紫或中性色进行多选筛选；圆点提供无文字 aria-label 和 title。                                                     |
| 亮度最小值/最大值   | 始终显示           | 设置 0 到 1 的亮度范围，输入值会被限制在合法范围内。                                                                                       |
| 饱和度最小值/最大值 | 始终显示           | 设置 0 到 1 的饱和度范围。                                                                                                                 |
| 拍摄日期从/至       | 始终显示           | 设置拍摄日期起止范围。                                                                                                                     |

左侧底部的“原图只读”是安全状态提示，不是按钮；旁边显示 `TinyCLIP · CPU` 或“语义模型未就绪”。

### 5.3 中央网格与图片卡片

| 控件               | 条件               | 行为                                                                                                                                     |
| ------------------ | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |

| 图片卡片单击       | 每张图片卡片       | 激活图片并在右侧打开详情；Ctrl/Command 可切换单张选择，Shift 从选择锚点直接选择连续范围。                                                |
| 已选图片拖动       | 至少一张图片已选   | 拖动已选图片中的任意一张时，整个选中集合一起移动到目标图库；拖动未选图片时只移动该图片。                                                 |

| 星级按钮/色标按钮  | 每张图片卡片       | 卡片底部直接设置星级或色标；点击已生效的同一标记可清除。已选中多张图片时，点击其中任意一张的标记会应用到整个选中集合。                   |

| 分析状态筛选条     | 存在未完成语义分析 | 显示在中央图片区域上方；可筛选“尚未语义分析”或“分析失败”，再次点击当前项取消。无未完成分析时自动隐藏。                                   |

点击网格空白区域会清除批量选择。点击文件名较长的卡片时，完整名称可通过 `title` 查看。

### 5.4 扫描进度面板

扫描启动后显示后台任务面板，阶段包括“准备图库”“发现图片”“生成索引与缩略图”“扫描完成”“扫描已取消”和“扫描失败”。

| 控件     | 条件                 | 行为                                                |
| -------- | -------------------- | --------------------------------------------------- |

进度面板显示发现、完成、失败、跳过、缺失数量、进度条、当前路径和错误详情。原始路径使用 `title` 保留完整内容。

### 5.5 语义任务条

语义任务运行或暂停时显示在中央区域上方，显示处理进度、实际执行后端、失败数和模型信息。

| 控件 | 条件                     | 行为                                   |
| ---- | ------------------------ | -------------------------------------- |
| 暂停 | 语义分析运行中           | 协作式暂停当前任务。                   |
| 继续 | 语义分析已暂停           | 恢复当前任务。                         |
| 取消 | 语义任务运行/暂停/取消中 | 请求取消任务；剩余资产不会生成伪标签。 |

语义任务使用单 worker，单项失败后继续后续资产；应用重启时已完成结果保留，运行中的项目可恢复排队。

### 5.6 右侧“图片详情”面板

| 控件           | 条件                               | 行为                                                               |

| 重新分析此图片 | 已选图片、模型 ready、基础分析完成 | 对当前图片重新发起语义分析；模型未就绪或图片基础分析未完成时禁用。 |

网格模式初次载入且存在结果时，右侧默认显示当前结果的第一张图片信息；点击其它图片后切换到对应详情。只有没有可展示的图片时，才显示“未选择图片”和使用说明。详情面板显示：

- EXIF：相机、镜头、曝光、光圈、ISO、焦距；

- 语义标签：一级分类/辅助标签、相似度进度条、模型、版本、后端。

## 6. 键盘与无障碍交互

- `Enter`：网格中有活动图片时进入单图预览。
- `Escape`：单图模式返回网格；网格模式清除批量选择。
- `ArrowLeft` / `ArrowRight`：单图模式切换前后图片。
- `0`：清除星级；`1`–`5`：设置星级；`[` / `]`：降低/提高一级星级。
- `6` / `7` / `8` / `9`：设置红/黄/绿/蓝色标；再次按当前已设置的同一快捷键会清除该色标。当前图片属于批量选择集合时，这些操作会应用到整个集合；未选中集合时只作用于当前图片。
- 图片卡片使用 `aria-pressed` 表示活动和选择状态。
- 扫描进度使用 `role="progressbar"` 和数值属性。
- 错误消息使用 `role="alert"`，任务状态使用可读文本。
- 面板、搜索框、排序、筛选、图片网格和胶片栏提供语义化 aria-label。

## 7. 当前安全边界与未开放功能

### 已实现的安全措施

- 扫描和分析只读源图库。
- 缩略图、数据库、模型和日志存储在应用数据目录。
- 扫描、语义分析和整理计划都支持错误隔离或问题诊断。
- 整理规划检查路径越界、非法段、保留名、路径长度、冲突和源文件变化。
- 导出计划使用 `create_new`，不覆盖已有文件，也不允许写入源图库。
- 从图库移除不调用源目录删除、移动或重命名 API。

### 当前明确未开放

- 复制到目标目录的执行动作；
- 移动、重命名、覆盖、永久删除；
- 生成副本后的回滚执行；
- 人脸身份识别；
- 视频和专业 RAW 显影；
- 云同步、远程后端、账号和订阅；
- 模型训练或自动生成描述。

文件复制、操作日志、撤销和恢复的数据表边界已经预留，但前端没有执行命令，不能把整理预览当成实际整理完成。
