# PhotoOrganizer 当前功能与界面说明

> 文档状态：基于当前 `main` 分支代码整理。
> 适用版本：`package.json` 中的 `0.1.0`。
> 运行形态：Tauri 2 桌面应用；Vite 浏览器预览仅用于界面验收。

## 1. 产品定位

PhotoOrganizer 是 Windows 优先、本地优先的照片管理工作台。它把“图片的虚拟分类结果”和“磁盘上的真实目录结构”分开保存：用户可以扫描、分析、筛选、预览图片，并生成整理目录与文件名的只读计划，但正常浏览和分析不会修改原始照片。

当前代码的核心原则如下：

- 只扫描用户明确选择的根目录，递归识别 JPEG、JPG、PNG 和 WebP，扩展名不区分大小写。
- SQLite 保存图库、资产、扫描任务、缩略图索引、传统特征、语义结果和整理预览计划。
- 缩略图、屏幕预览、模型和日志保存在应用数据目录，不写回源图库。
- 单张图片分析失败不会终止整次扫描或语义任务。
- 扫描和语义分析在后台运行，并通过进度事件更新界面。
- 当前没有真实的复制、移动、重命名、覆盖或删除源文件的执行入口。
- “整理预览”是 dry-run：只生成源路径到规划目标路径的映射；导出 JSON/CSV 是唯一由用户明确触发的文件写入。

## 2. 当前实现范围与运行模式

### 2.1 Tauri 桌面模式

桌面模式由 Tauri 承载 React/TypeScript 界面，Rust 负责：

- 目录遍历、文件 fingerprint 和增量扫描；
- EXIF/基本元数据读取；
- 缩略图和屏幕预览生成；
- 亮度、对比度、饱和度、色度、主色和中性色比例分析；
- SQLite 初始化、迁移、筛选、排序、分组和任务持久化；
- 随包 TinyCLIP INT8 + ONNX Runtime 的本地 CPU 语义分类；
- 整理规则校验、目标路径规划、冲突诊断和清单导出。

前端通过类型化 Tauri command/response 和 `scan-progress`、`semantic-progress` 事件与 Rust 通信。应用不开放远程后端或网络服务。

### 2.2 Vite 浏览器预览模式

开发服务器可以使用确定性的视觉夹具，不读取 SQLite、不打开系统目录选择器、不访问个人照片：

```text
http://localhost:1420/?visual-fixture=library
http://localhost:1420/?visual-fixture=scanning
http://localhost:1420/?visual-fixture=error
```

浏览器预览可以体验图库、筛选、排序、选择、详情、单图预览和扫描/语义任务的视觉状态。需要桌面能力的操作会被禁用、返回空结果或显示“仅在桌面应用中可用”，例如真实导入、真实扫描、真实模型准备、重新分析和 Explorer 操作。

## 3. 功能总览

### 3.1 建立与维护图库

1. 首次启动显示“建立本地图片库”空状态。
2. 点击导入后，通过系统目录选择器选择根目录。
3. Rust 后台递归扫描 JPEG/JPG、PNG、WebP。
4. 扫描阶段记录发现、处理、成功、失败、跳过和缺失数量。
5. 扫描完成后将本轮未发现的既有资产标记为缺失；扫描取消不会把尚未遍历的文件误标为缺失。
6. 重复扫描按库内绝对路径和 fingerprint 增量更新；源文件大小或修改时间变化会使相关缓存/分析结果失效。
7. 图库菜单支持重新扫描、在资源管理器中显示、查看图库信息和从 PhotoOrganizer 索引中移除。
8. “从资料库移除”只清理应用索引、分析结果、任务和应用缓存，不删除或修改源文件。

### 3.2 元数据、缩略图和传统图像分析

扫描后资产可保存并展示：

- 文件格式、大小、修改时间、相对路径；
- 宽度、高度和方向；
- 拍摄时间；
- 相机品牌/型号、镜头、曝光时间、光圈、ISO、焦距等常见 EXIF 字段；
- 应用私有缩略图；
- 亮度、对比度、饱和度、色度；
- 影调等级：低调、均衡、高调；
- 主色十六进制值、主色类别、彩色主色覆盖率、中性色比例；
- 饱和度等级和分析完成/失败状态。

导入时每张图片只生成一份不超过 `640×640` 的应用私有缩略图；亮度、对比度、饱和度和主色等基础特征从同一份缩略图像素缓冲区采样计算。缩略图缓存和基础分析使用显式版本，旧版本缓存会在重新扫描时失效重建。不超过 32MB 的源图在导入阶段一次读入，同时复用完整内容 fingerprint 和解码字节；更大的源图仍采用受内存约束的流式 fingerprint。

缩略图用于网格和胶片栏；单图预览先加载屏幕尺寸预览，放大到 100% 或更高时按需读取原图。请求使用 generation token，切换图片时会忽略旧请求，不会把预览资源写回原图库。

### 3.3 浏览、筛选、排序和分组

图库支持：

- 文件名或路径搜索；
- 原始目录前缀筛选；
- 语义标签筛选；
- 语义标签“任一标签”或“同时包含”匹配；
- 尚未语义分析、分析失败快捷筛选；
- 影调筛选；
- 主色类别筛选；
- 亮度范围和饱和度范围筛选，范围为 0 到 1；
- 拍摄日期起止筛选；
- 按文件名、拍摄时间、修改时间、亮度、饱和度排序；
- 升序/降序切换；
- 按一级语义标签分组；
- 分页浏览，前端当前页大小为 120，实际查询由 SQLite 层完成。

组合筛选会在顶部显示已应用筛选数量，并提供“清除筛选”。文件夹、标签和数值筛选可以叠加。

### 3.4 语义分类

语义分类使用随应用分发的 TinyCLIP INT8 模型，在本机 ONNX Runtime CPU 后端执行。结果保存：

- 标签 ID 和中文显示名；
- 原始相似度和阈值；
- 模型名称、模型版本、分析版本；
- 分析时间、来源 fingerprint；
- 一级分类/辅助标签标记。

当前语义标签目录包含：人像、多人、风景、城市/建筑、室内、街道、车辆、静物/产品、静物、食品、动物、截图、文档/截图、夜景、花卉、山、水体、森林、日落、抽象、未知。

一级分类用于主分组和左侧内容标签，当前为人像、风景、城市/建筑、静物/产品、动物、文档/截图、未知。夜景、山、水体、森林、花卉、日落等作为辅助标签参与详情展示和语义查询。

语义状态包括模型未就绪/不可用、排队、运行、暂停、取消中、完成和失败。模型不可用时，基础图库、缩略图、传统影调色彩分析仍然可用，界面不会伪造语义标签。

### 3.5 图片选择与预览

网格中的图片支持：

- 单击激活图片并在右侧显示详情；
- 点击卡片左上角选择/取消选择；
- Ctrl/Command 点击进行多选或反选；
- Shift 点击选择连续范围；
- 双击进入单图预览；
- 选中图片后按 Enter 进入单图预览；
- 网格空白区域点击清除批量选择；
- Esc 清除选择，或在单图模式返回网格。

单图模式提供胶片栏、按当前筛选和排序结果导航、高清预览、Fit/25/50/100/200/400% 缩放、滚轮缩放、指针中心缩放和放大后的拖动画布。

### 3.6 整理预览 Dry-run

“整理预览”用于在真实文件操作前审查目标目录和命名计划。用户可以：

- 选择当前筛选结果、全部图片或用户选中图片作为范围；
- 输入或选择目标根目录；
- 添加、删除、拖动和上下移动目录维度；
- 为每一层目录设置缺失值回退策略；
- 编辑命名模板；
- 设置缺失元数据策略；
- 设置重名策略：添加序号、添加 short hash、跳过；
- 设置序号起点和序号宽度；
- 生成目标目录树和逐文件映射；
- 查看文件数、冲突数、错误数、警告数和预计字节数；
- 点击单条映射查看源路径、规划目标路径、模板变量和问题；
- 导出 JSON 或 CSV dry-run 清单。

规划器会检查源缺失、源文件变化、缺失元数据、非法路径段、Windows 保留名、路径过长、目标越界、重复目标和已存在目标等问题。目标根目录不会被创建，不能位于源图库内部；当前版本没有执行复制按钮。

## 4. 主界面布局

主界面由四个主要区域组成：

```text
顶部工具栏
┌──────────────────────────────────────────────────────────────┐
│ 图库身份/统计 │ 视图 搜索 筛选 排序 导入 语义 整理预览        │
├───────────────┬──────────────────────────────┬───────────────┤
│ 左侧图库与筛选 │ 中央网格 / 单图 / 整理预览 │ 右侧图片详情   │
└───────────────┴──────────────────────────────┴───────────────┘
```

左侧和右侧面板都可折叠。面板折叠后保留展开按钮和简化图标，以便释放中央画布空间。

### 5.3 中央网格与图片卡片

| 控件               | 条件         | 行为                                                            |
| ------------------ | ------------ | --------------------------------------------------------------- |
| 清除筛选           | 存在活动筛选 | 清空所有搜索、标签、影调、颜色、数值、日期和语义状态筛选。      |
| 按主要语义标签分组 | 已建立图库   | 勾选后按一级语义标签分区显示；未分析图片进入“未分析”分组。      |
| 选择/取消选择      | 每张图片卡片 | 修改批量选择状态，按钮使用 `aria-pressed` 表示选中状态。        |
| 图片卡片单击       | 每张图片卡片 | 激活图片并在右侧打开详情；支持 Ctrl/Command 多选和 Shift 连选。 |
| 图片卡片双击       | 每张图片卡片 | 进入单图预览。                                                  |
| 上一页/下一页      | 总页数大于 1 | 在当前查询结果分页；边界页按钮禁用。                            |

发生启动、查询或后台任务错误时，中央区域会显示全局错误提示；提示中的“关闭”按钮只隐藏当前错误，不会撤销已经完成的扫描、分析或索引操作。

每张卡片显示缩略图、文件名、主色圆点、亮度、饱和度和最多两个语义标签。源文件缺失或分析失败时，卡片显示对应警告文本。

点击网格空白区域会清除批量选择。点击文件名较长的卡片时，完整名称可通过 `title` 查看。

### 5.4 扫描进度面板

扫描启动后显示后台任务面板，阶段包括“准备图库”“发现图片”“生成索引与缩略图”“扫描完成”“扫描已取消”和“扫描失败”。

| 控件     | 条件                 | 行为                                                |
| -------- | -------------------- | --------------------------------------------------- |
| 取消扫描 | 扫描运行中           | 发送取消请求；请求处理中显示“正在取消…”并禁用按钮。 |
| 关闭状态 | 扫描已完成/取消/失败 | 从界面隐藏终态进度面板，不删除已生成的索引。        |

进度面板显示发现、完成、失败、跳过、缺失数量、进度条、当前路径和错误详情。原始路径使用 `title` 保留完整内容。

### 5.5 语义任务条

语义任务运行或暂停时显示在中央区域上方，显示处理进度、实际执行后端、失败数和模型信息。

| 控件 | 条件                     | 行为                                   |
| ---- | ------------------------ | -------------------------------------- |
| 暂停 | 语义分析运行中           | 协作式暂停当前任务。                   |
| 继续 | 语义分析已暂停           | 恢复当前任务。                         |
| 取消 | 语义任务运行/暂停/取消中 | 请求取消任务；剩余资产不会生成伪标签。 |

语义任务使用单 worker，单项失败后继续后续资产；应用重启时已完成结果保留，运行中的项目可恢复排队。

### 5.6 右侧“图片详情”面板

| 控件              | 条件                               | 行为                                                               |
| ----------------- | ---------------------------------- | ------------------------------------------------------------------ |
| 展开/折叠右侧面板 | 始终显示                           | 收起详情面板为窄栏，或恢复完整详情。                               |
| 重新分析此图片    | 已选图片、模型 ready、基础分析完成 | 对当前图片重新发起语义分析；模型未就绪或图片基础分析未完成时禁用。 |

没有选择图片时显示“未选择图片”和使用说明。选择图片后显示：

- 文件：格式、尺寸、大小、拍摄时间；
- EXIF：相机、镜头、曝光、光圈、ISO、焦距；
- 影调与色彩：亮度、对比度、饱和度、色度、有彩色占比、中性色占比、影调和主色；
- 语义标签：一级分类/辅助标签、相似度进度条、模型、版本、后端。

语义数值明确标注为“模型相似度”，不代表准确率或概率。

### 5.7 单图预览与胶片栏

| 控件/操作               | 行为                                               |
| ----------------------- | -------------------------------------------------- |
| 胶片栏图片按钮          | 切换当前预览图片；胶片栏只显示当前查询结果。       |
| −                       | 按 25% 步长缩小，最低 25%。                        |
| 适应窗口                | 将图片缩放到画布可见区域并重置偏移。               |
| 100%                    | 以原始像素比例显示，并按需读取原图。               |
| 25% / 50% / 200% / 400% | 直接切换到对应缩放比例；最高 400%。                |
| ＋                      | 按 25% 步长放大，最高 400%。                       |
| 鼠标滚轮                | 以指针位置为中心缩放，并限制拖动边界。             |
| 拖动画布                | 只有图片大于适应窗口比例时可拖动，偏移受边界限制。 |
| 双击画布                | 在 Fit 和 100% 之间切换。                          |
| 左右方向键              | 在单图预览中切换前后图片，跨页时加载下一页结果。   |
| Esc                     | 返回网格模式。                                     |

单图预览加载失败时保留缩略图并显示错误提示；原图读取失败时仍可使用屏幕预览。

### 5.8 整理预览工作区

进入整理预览后，顶部安全横幅明确标注“只读整理预览”。

| 控件             | 行为                                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 返回图库         | 返回三栏图库工作区，不执行任何文件操作。                                                                                                      |
| 当前筛选结果     | 将当前查询结果作为整理范围。                                                                                                                  |
| 全部图片         | 将图库中全部存在的图片作为整理范围。                                                                                                          |
| 用户选中         | 仅将批量选中的图片作为整理范围；没有选中图片时生成会报错。                                                                                    |
| 目标根目录输入框 | 手动输入目标目录路径。                                                                                                                        |
| 选择             | 打开目录选择器；目标目录不会被创建。                                                                                                          |
| 第 N 层目录维度  | 选择年、月、日、原始目录、主要语义、影调、主色或饱和度等级。                                                                                  |
| 第 N 层缺失回退  | 选择修改时间回退、未知、跳过维度或阻止此项。                                                                                                  |
| 上移/下移第 N 层 | 调整目录维度顺序，首层不能上移，末层不能下移。                                                                                                |
| 删除第 N 层      | 删除该目录维度。                                                                                                                              |
| + 添加维度       | 新增一个“日 / 修改时间回退”维度。                                                                                                             |
| 目录维度拖动     | 拖动目录维度改变顺序。                                                                                                                        |
| 文件命名模板     | 编辑文件名变量模板。支持 capture_time、camera、lens、original_name、semantic、tone、dominant_color、saturation、sequence、short_hash 等变量。 |
| 缺失元数据       | 设置缺失元数据时的默认策略。                                                                                                                  |
| 重名策略         | 选择添加序号、添加 short hash 或跳过。                                                                                                        |
| 序号起点         | 设置序列起始值，最小为 1。                                                                                                                    |
| 序号宽度         | 设置序列补零宽度，范围 1 到 12。                                                                                                              |
| 生成整理预览     | 校验规则并生成目标目录树、完整源/目标映射和问题清单。目标为空或规则不安全时显示错误。                                                         |
| 导出 JSON        | 通过另存为对话框导出完整 dry-run 计划；拒绝覆盖已有文件。                                                                                     |
| 导出 CSV         | 导出逐文件清单；同样拒绝覆盖已有文件。                                                                                                        |
| 映射行           | 选中一条映射，在右侧查看源路径、目标路径、模板变量和检查结果。                                                                                |

工作区还显示文件、冲突、错误、警告、估算字节数、目标空间未探测提示、目标目录树和完整映射表。当前没有“执行整理”“复制”“回滚”按钮。

## 6. 键盘与无障碍交互

- `Enter`：网格中有活动图片时进入单图预览。
- `Escape`：单图模式返回网格；网格模式清除批量选择。
- `ArrowLeft` / `ArrowRight`：单图模式切换前后图片。
- 图片卡片使用 `aria-pressed` 表示活动和选择状态。
- 扫描进度使用 `role="progressbar"` 和数值属性。
- 错误消息使用 `role="alert"`，任务状态使用可读文本。
- 面板、搜索框、排序、筛选、图片网格和胶片栏提供语义化 aria-label。

## 7. 当前安全边界与未开放功能

### 已实现的安全措施

- 扫描和分析只读源图库。
- 缩略图、数据库、模型和日志存储在应用数据目录。
- 扫描、语义分析和整理计划都支持错误隔离或问题诊断。
- 整理规划检查路径越界、非法段、保留名、路径长度、冲突和源文件变化。
- 导出计划使用 `create_new`，不覆盖已有文件，也不允许写入源图库。
- 从资料库移除不调用源目录删除、移动或重命名 API。

### 当前明确未开放

- 复制到目标目录的执行动作；
- 移动、重命名、覆盖、永久删除；
- 生成副本后的回滚执行；
- 人脸身份识别；
- 视频和专业 RAW 显影；
- 云同步、远程后端、账号和订阅；
- 模型训练或自动生成描述。

文件复制、操作日志、撤销和恢复的数据表边界已经预留，但前端没有执行命令，不能把整理预览当成实际整理完成。
